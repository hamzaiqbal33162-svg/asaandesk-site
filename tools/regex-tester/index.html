How to use Regex Tester

  1. Type or paste your text.
  2. Choose the options.
  3. Press the button and copy or download the result.

What does this tool do?

Type the pattern without slashes (or as /pattern/flags) and paste the text in the box. Choose the flags; named groups and $1 / $<name> replacements work, as in JavaScript.

Example\d{4}-\d{7} → 2 matches

What a regex tester is for

A regular expression (regex) is a small pattern language for finding text: phone numbers, email addresses, dates, invoice codes or anything with a predictable shape. Programmers use them in code and form validation, and analysts use them in spreadsheets and text editors. Writing a pattern blind is error-prone, so a tester lets you paste real text and see exactly what the pattern catches before you rely on it.

How this tester works

It uses the JavaScript regular expression engine built into your browser, so the behaviour matches what you get in web pages and Node.js. Type the pattern on its own, or in the /pattern/flags form. Global search is always on so every match is found; you can add ignore case (i), multiline anchors (m), dot matches new lines (s) and Unicode mode (u) with check boxes.

There are three views. Matches and groups lists each match with its line, column and character index, followed by every numbered and named capture group, or (not matched) when a group took no part. Only the matched text gives a plain list, one match per line, which is useful for pulling all emails out of a page. Replace runs a substitution where $& is the whole match, $1 is the first group and $<name> a named group. Up to 1,000 matches are listed from as much as 200,000 characters of text, and the test runs in a separate worker that is stopped after 5 seconds if a pattern runs away.

Worked example

Text: Call 0300-1234567 or 0321-7654321. Pattern: \d{4}-\d{7}. The result reports 2 matches: #1 at line 1, column 6 (index 5) with "0300-1234567", and #2 at line 1, column 22. Change the pattern to (\d{4})-(\d{7}), switch to Replace and enter $1$2 as the replacement, and the text becomes Call 03001234567 or 03217654321 with the summary 2 replacements made.

Common mistakes

ProblemFix
A dot matches any character, not just a full stopEscape it as \. when you mean a literal dot
.* grabs far more than expectedUse the lazy form .*? or a narrower class such as [^,]*
^ and $ only match the whole textTurn on the m flag to match at every line
Pattern freezes on long textAvoid nested repeats like (a+)+ and make each part more specific

Good to know

What are the limits?

Uses JavaScript regular expressions. A pattern that runs too long is stopped after 5 seconds.

Input up to 200,000 characters · 1,000 matches listed is supported.

Is my file uploaded?

No. The tool's code is downloaded; your file or input is not sent to a server for conversion. Closing the browser stops the work.

How long does it take?

Text and small inputs are usually processed quickly. PDFs, images and audio take longer depending on their size, codec and the speed of your device.
