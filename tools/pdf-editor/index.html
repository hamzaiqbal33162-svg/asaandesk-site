How to use PDF Editor

  1. Open the PDF Editor and choose your PDF, JPG or PNG file.
  2. Click any text to change it, or add text, an image, a signature or a cover from the toolbar.
  3. Press Download PDF and save the new file.

What does this tool do?

Finds and outlines the text in a PDF or image. Click any text to change or delete it; font, size and colour are matched automatically. Merging, rotating and saving pages as PNG are in the same editor.

Exampleinvoice.pdf → invoice.pdf with a new name and date

Good to know

What are the limits?

Text in scanned PDFs is read with OCR, which takes a little time the first time.

Input up to Large PDFs too, up to your device memory is supported.

Is my file uploaded?

No. The tool's code is downloaded; your file or input is not sent to a server for conversion. Closing the browser stops the work.

How long does it take?

Text and small inputs are usually processed quickly. PDFs, images and audio take longer depending on their size, codec and the speed of your device.

Can I edit the existing text in a PDF for free?

Yes. Click any text to change or delete it; the font, size and colour are matched to the original. You can also add text, images and signatures, with no sign-up or payment.

Does the edited PDF get a watermark?

No. The edited PDF downloads without any watermark.

Can I edit a scanned PDF?

Yes. Text in a scan or a photo is read with OCR first, which takes a little time the first time. PDF Editor Pro also reorders and merges pages.
