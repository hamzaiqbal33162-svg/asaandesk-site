How to use Document Metadata Cleaner

  1. Drop a Word, Excel, PowerPoint or PDF file here or choose it.
  2. Check the report of what the file holds.
  3. Press Clean document and download the clean copy.

What does this tool do?

DOCX, XLSX and PPTX: the document properties, company, manager, editing time, template and custom properties are cleared, and author names in comments and tracked changes are replaced. PDF: the Info dictionary, XMP metadata, app private data, the file ID and older saved versions are removed.

Examplebudget.docx (Jane Example, Example Traders) → budget-clean.docx, same text and layout

Good to know

What are the limits?

Comments and tracked changes themselves stay (only their author names change); delete them in your office app if they should not be shared. A digitally signed PDF loses its signature when it is cleaned.

Input up to 100 MB is supported.

Is my file uploaded?

No. The tool's code is downloaded; your file or input is not sent to a server for conversion. Closing the browser stops the work.

How long does it take?

Text and small inputs are usually processed quickly. PDFs, images and audio take longer depending on their size, codec and the speed of your device.

How do I remove the author name from a Word document?

Choose the DOCX file and press Clean document. The author, last modified by, company, manager and custom properties are cleared, and the names on comments and tracked changes become "Author".

Does it delete comments and tracked changes?

No, they stay so your document does not change; only the names on them are replaced. Delete or accept them in Word, Excel or PowerPoint if they should not be shared.

What is removed from a PDF?

The document properties (title, author, subject, keywords, the apps that made it, dates), XMP metadata, app private data, the file ID and older saved versions inside the file. To change only the title or author, use Edit PDF Metadata.
