How to use CSV to JSON

  1. Paste your text into the input box.
  2. Choose options and run the tool.
  3. Copy the result or download the file.

What does this tool do?

The first row must have unique column names. Quoted commas, escaped quotes and quoted newlines are supported. Values stay strings.

Examplename,city → JSON objects

When CSV to JSON is useful

Spreadsheets, bank statements, contact exports and form results are often saved as CSV, while web apps, APIs and JavaScript code usually expect JSON. Converting a small CSV export into a JSON array lets you paste it straight into a test request, a configuration file or a seed script without writing a parser yourself.

Each row after the header becomes one object, and each header cell becomes a key in every object. The result is an array of objects, printed with two spaces of indent so it is easy to read and check before you use it.

A worked example

Suppose your CSV is three lines: name,city,note then Ali,Karachi,"Likes tea, not coffee" then Sara,Lahore,"She said ""hi""". The quoted comma in the first note stays inside the value, and the doubled quotes in the second note become a single quote character. The output is an array with two objects, each with the keys name, city and note.

Numbers are not turned into JSON numbers. A cell like 42 becomes the string "42", and an empty cell becomes an empty string. This avoids silent changes such as losing the leading zero in a phone number or postal code.

How the parser reads your file

Input detailWhat happens
Comma between cellsStarts a new cell (only commas are separators)
Text in double quotesCommas and line breaks inside it stay in the value
Two double quotes inside quotesBecome one double quote
Windows (CRLF) or Unix (LF) line endsBoth are read as a new row
Byte order mark at the startRemoved before reading
Quote that is never closedError: the quote is not closed

Common mistakes and fixes

A blank line in the middle of the data counts as a row with one empty cell, so it triggers the wrong-number-of-columns error. Delete empty lines before converting. A single trailing line break at the end of the file is fine.

If your file uses semicolons or tabs between cells, as some European spreadsheet settings do, the whole line is read as one cell. Re-export the file as comma-separated, or replace the separators first. Text pasted from a spreadsheet often uses tabs, so check this when the output looks like one long key.

A stray quote in the middle of an unquoted cell, such as 5" screen, is rejected. Wrap that cell in quotes and double the inner quote: "5"" screen".

Good to know

What are the limits?

Blank or duplicate headers and mismatched columns show an error.

Input up to 200,000 characters is supported.

Is my file uploaded?

No. The tool's code is downloaded; your file or input is not sent to a server for conversion. Closing the browser stops the work.

How long does it take?

Text and small inputs are usually processed quickly. PDFs, images and audio take longer depending on their size, codec and the speed of your device.
