What does this tool do?

Convert data sizes in base 1024 (binary) to make sense of files and internet packages.

Example1 GB = 1024 MB

Bits, bytes and the units in between

Computers store data in bytes; one byte is 8 bits. File sizes, phone storage and mobile data packages are given in KB, MB, GB and TB. This converter uses base 1024, the way operating systems such as Windows show file sizes: 1 KB = 1024 bytes, 1 MB = 1024 KB and so on.

Why a 1 TB drive shows less space

Drive makers count 1 TB as 1,000,000,000,000 bytes (base 1000). Windows divides by 1024 at each step, so the same drive appears as about 931 GB. No space is missing; it is the same number of bytes counted in two ways.

Internet speed vs file size

Internet speed is measured in megabits per second (Mbps), while file sizes are in megabytes (MB). Because a byte is 8 bits, a 20 Mbps connection downloads at most about 2.5 MB per second, so a 500 MB file takes roughly 3–4 minutes in good conditions.

Is my file uploaded?

No. The tool's code is downloaded; your file or input is not sent to a server for conversion. Closing the browser stops the work.

How long does it take?

Text and small inputs are usually processed quickly. PDFs, images and audio take longer depending on their size, codec and the speed of your device.
