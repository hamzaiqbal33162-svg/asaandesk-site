How to use Excel to CSV

  1. Choose a file from your device, drop it here or paste a file link.
  2. Check the options and press Convert.
  3. Download the finished file.

What does this tool do?

Values are saved as Excel shows them, dates as 2024-03-05. Pick one sheet or all sheets (one CSV each, in a ZIP).

Examplesales.xlsx → sales.csv

Good to know

What are the limits?

Formulas are saved as their last calculated value. Old .xls files must be saved as .xlsx first.

Input up to 30 MB is supported.

Is my file uploaded?

No. The tool's code is downloaded; your file or input is not sent to a server for conversion. Closing the browser stops the work.

How long does it take?

Text and small inputs are usually processed quickly. PDFs, images and audio take longer depending on their size, codec and the speed of your device.
