How to use Hash Generator (MD5, SHA-256)

  1. Type or paste your text.
  2. Choose the options.
  3. Press the button and copy or download the result.

What does this tool do?

The text is read as UTF-8, exactly as typed. Choose one algorithm or see all at once; add a secret key for HMAC, or hash each line separately. CRC-32 and SHA-384 are also available.

Examplehello → 5d41402abc4b2a76b9719d911017c592 (MD5)

What a hash is

A hash function turns any amount of text into a short fixed-length fingerprint. The same input always gives the same hash, and changing even one letter gives a completely different result. Developers use hashes to compare values without storing them, to build cache keys and API signatures, and to check that data was not altered. Unlike encryption, a hash cannot be turned back into the original text.

How this tool works

Type or paste up to 200,000 characters. The text is turned into bytes as UTF-8 exactly as typed, including spaces and line breaks, and then hashed. By default you see MD5, SHA-1, SHA-256 and SHA-512 together; you can also choose one of those alone, SHA-384 or CRC-32. Output can be lower-case hex, upper-case HEX or Base64.

If you enter a secret key, the tool computes an HMAC instead, which is how many payment gateways and webhooks sign their messages. CRC-32 is a checksum, not a keyed hash, so the key does not apply to it. You can also hash each line separately, up to 1,000 lines, which is handy for a list of IDs or emails.

A worked example and common mistakes

The MD5 of hello is 5d41402abc4b2a76b9719d911017c592. Type Hello with a capital H and the hash is entirely different. A frequent surprise is a trailing line break: text copied from a file often ends with one, and that changes the hash. The tool warns you when your text ends with a line break.

MD5 and SHA-1 have known collision attacks, so do not use them for security. Plain fast hashes of any kind are also not suitable for storing passwords; password storage needs slow, salted functions such as bcrypt, scrypt or Argon2.

Good to know

What are the limits?

MD5 and SHA-1 are fine for checksums, not for storing passwords.

Input up to 200,000 characters is supported.

Is my file uploaded?

No. The tool's code is downloaded; your file or input is not sent to a server for conversion. Closing the browser stops the work.

How long does it take?

Text and small inputs are usually processed quickly. PDFs, images and audio take longer depending on their size, codec and the speed of your device.
