Medical Certificate Template (Doctors)

Doctors aur clinics ke liye medical/fitness certificate template.

Free · Bina sign-upBrowser mein processing

Sirf registered doctors aur clinics ke liye. Certificate print karne ke baad doctor khud sign aur stamp karein. Ghalat ya jaali medical certificate banana qanoonan jurm hai.

Print window mein "Save as PDF" chunein. Aap ka draft isi browser mein save rehta hai.

Clinic / Hospital ka naam

Dr. ________MBBSPMDC Reg. No: ________

MEDICAL CERTIFICATE (SICK LEAVE)

Serial No: ______Date: 07/11/2026

This is to certify that ____________ aged __ years (Male), was examined by me on 07/11/2026.

He/She is suffering from ____________ and is advised rest from 07/11/2026 to __________.

Doctor's signature
Stamp

Valid only with the doctor's original signature and stamp.

  1. Template chunein.

  3. Print / PDF save karein.

Is tool se kya hota hai?

Registered doctor apni clinic, PMDC number aur mareez ki details bhar kar certificate print karein aur khud sign/stamp karein.
