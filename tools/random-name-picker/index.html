How to use Random Name Picker

  1. Type or paste your text.
  2. Choose the options.
  3. Press the button and copy or download the result.

What does this tool do?

Type one name per line (or separate them with commas). Choose how many winners or teams. Duplicate names can be removed first.

ExampleAli, Sara, Bilal, Ayesha → Winner: Bilal

When a fair random pick is needed

Teachers choose who answers next or who presents first, offices pick a winner for a lucky draw, event hosts select prize winners from entries, and sports coaches split players into sides. Doing it by hand invites complaints of favouritism. A random picker gives everyone the same chance and makes the result quick and visible.

How names are read and picked

Type or paste one name per line. If everything is on a single line, commas or semicolons separate the names instead. Numbering such as "1." or "2)" and list bullets at the start of a line are removed, so a list copied from a document works. With Remove duplicate names ticked, a name that appears twice is kept once, ignoring capital letters, so "Ali" and "ali" count as one entry.

The list is shuffled with the Fisher-Yates method, and each random choice comes from the browser's cryptographic random number generator rather than a simple pseudo-random formula. Every order of the names is equally likely. You need at least two names, and up to 10,000 can be used.

The three modes

In team mode the shuffled names are dealt out in turn like playing cards, so team sizes never differ by more than one.

Tips for a transparent draw

Share the full list of entries before you press Pick, run the draw where people can see the screen, and save the result file (winners.txt, shuffled-list.txt or teams.txt) as a record. Decide in advance whether duplicate entries are allowed; for a draw where buying more tickets gives more chances, untick Remove duplicate names and enter each ticket separately. For a fair second prize, pick several winners at once rather than drawing again, which could choose the same person.

Good to know

What are the limits?

Uses secure random numbers; every name has the same chance.

Input up to 10,000 names is supported.

Is my file uploaded?

No. The tool's code is downloaded; your file or input is not sent to a server for conversion. Closing the browser stops the work.

How long does it take?

Text and small inputs are usually processed quickly. PDFs, images and audio take longer depending on their size, codec and the speed of your device.
