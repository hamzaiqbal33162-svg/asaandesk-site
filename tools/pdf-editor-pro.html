What PDF Editor Pro is for

Small corrections are the most common reason to edit a PDF: a misspelt name on a certificate, a wrong date on a form, an outdated phone number on a flyer. PDF Editor Pro is the editor from the AsaanDesk PDF Editor browser extension, offered on the website. It lets you change existing text, add new text, pictures and signatures, merge PDFs and change the order of pages. It accepts PDF, PNG and JPEG files.

Why editing PDF text is harder than it looks

A PDF does not store paragraphs the way a word processor does. It stores instructions that place each run of characters at an exact position in a particular font. To change a word, an editor has to find that run, remove it and draw new text in a matching font, size and colour. Many PDFs embed only the characters they actually use, a practice called font subsetting, so an editor sometimes has to match the look with a similar font for letters that were never in the file.

Scanned documents and photos contain no text at all, only pixels. Optical character recognition (OCR) is used to find the words in the image before they can be edited, and that step takes some time the first time it runs.

Tips for clean edits

Keep replacement text about the same length as the original so it fits the space, or the line may run into neighbouring text. Zoom in and compare the new text with the surrounding words before downloading. Save the result under a new name and keep the original, so you can start again if needed. Editing someone else's document, certificate or official record to misrepresent it can have serious consequences, so edit only documents you are entitled to change.

Good to know

What are the limits?

Reading text from a scanned PDF or image with OCR takes a little time the first time.

Input up to Large PDFs too, up to your device memory is supported.

Is my file uploaded?

No. The tool's code is downloaded; your file or input is not sent to a server for conversion. Closing the browser stops the work.

How long does it take?

Text and small inputs are usually processed quickly. PDFs, images and audio take longer depending on their size, codec and the speed of your device.
