# AsaanDesk

**https://asaandesk.com**: free online tools for PDF, images, video, audio and text, made in Pakistan.

More than 170 tools run in the browser. Most of them need no sign-up, and most process files on your own device
instead of uploading them.

This repository holds the built static site that GitHub Pages serves at asaandesk.com.

## Popular tools

- [PDF Editor](https://asaandesk.com/tools/pdf-editor): click any text in a PDF and change it in the same font.
- [PDF to Word](https://asaandesk.com/tools/pdf-to-word) and [Word to PDF](https://asaandesk.com/tools/word-to-pdf)
- [Compress PDF](https://asaandesk.com/tools/compress-pdf), [Merge PDF](https://asaandesk.com/tools/merge-pdf) and [Split PDF](https://asaandesk.com/tools/split-pdf)
- [Scan to PDF](https://asaandesk.com/tools/scan-to-pdf), with English and Urdu OCR
- [Background Remover](https://asaandesk.com/tools/background-remover): the AI runs in your browser.
- [Compress Image to KB](https://asaandesk.com/tools/compress-image-to-kb) for job and admission forms
- [Area Converter](https://asaandesk.com/tools/area-converter) (marla, kanal, sq ft) and [Weight Converter](https://asaandesk.com/tools/weight-converter) (tola, maund)
- [Zakat Calculator](https://asaandesk.com/tools/zakat-calculator) and [GPA & CGPA Calculator](https://asaandesk.com/tools/gpa-calculator)
- [Weather for Pakistani cities](https://asaandesk.com/weather): hourly and 7-day forecasts.
