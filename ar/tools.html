    حوّل ملف ZIP إلى TAR.GZ (أو .tgz) داخل متصفحك، وهي الصيغة المعتادة لخوادم Linux والرفع إلى cPanel والشيفرة المصدرية.
  • تحويل TAR إلى ZIP
    حوّل أرشيف TAR إلى ملف ZIP يُفتح بلمسة واحدة على Windows وMac وAndroid وiPhone، دون رفعه.
  • تحويل TAR إلى TAR.GZ
    اضغط أرشيف TAR إلى TAR.GZ (أو .tgz) باستخدام GZIP داخل متصفحك لتصغير حجمه كثيرًا قبل الرفع أو النسخ الاحتياطي.
  • تحويل TAR.GZ إلى ZIP
    حوّل ملف TAR.GZ إلى ZIP ليُفتح على أي جهاز Windows أو هاتف. تُحفظ المجلدات والأسماء والتواريخ، ولا يُرفع أي شيء.
  • تحويل TAR.GZ إلى TAR
    أزل ضغط GZIP من ملف TAR.GZ أو TGZ واحصل على أرشيف TAR العادي، داخل متصفحك.
  • تحويل TGZ إلى ZIP
    حوّل أرشيف TGZ إلى ZIP داخل متصفحك ليُفتح على Windows وMac والهواتف دون تطبيقات إضافية.
  • تحويل GZ إلى ZIP
    حوّل ملف .gz إلى ZIP. الملف المفرد المضغوط بـ gzip يدخل إلى ZIP كما هو، أما ملف .tar.gz فتظهر كل ملفاته.
  • تحويل JAR إلى ZIP
    حوّل ملف Java بصيغة JAR إلى ZIP عادي لتفتحه بأي تطبيق لفك الضغط وتطّلع على الفئات والموارد بداخله.
  • ضغط GZIP (إنشاء ملف .GZ)
    اضغط أي ملف منفرد إلى ملف .gz باستخدام GZIP داخل متصفحك. اختر ضغطًا سريعًا أو أقصى ضغط، ويُحفظ الاسم بداخله.
  • فتح ملف GZ (Gunzip)
    فك ضغط ملف .gz لاستعادة الملف الأصلي باسمه الحقيقي. يعمل مع ملفات .gz و.tgz و.svgz داخل متصفحك.
  • المجموع الاختباري للملف (MD5 وSHA-256)
    احصل على المجاميع الاختبارية MD5 وSHA-1 وSHA-256 وSHA-512 لأي ملف وقارنها بما يعرضه الموقع للتحقق من سلامة التنزيل.
  • تحويل الملف إلى Base64
    حوّل أي ملف (صورة أو PDF أو خط أو صوت) إلى نص Base64 أو data: URI لاستخدامه في HTML أو CSS أو JSON أو البريد الإلكتروني، دون رفعه.
  • تحويل Base64 إلى ملف
    الصق نص Base64 أو data: URI ونزّل الملف الحقيقي. يُكتشف النوع (PNG وPDF وMP3 وZIP…) من محتواه.
  • عارض الملفات بالنظام السداسي عشر
    اعرض البايتات الخام لأي ملف بالنظام السداسي عشر وكنص، واعرف نوعه الحقيقي من بايتاته الأولى، وانتقل إلى أي موضع.
  • مقسّم الملفات
    قسّم ملفًا كبيرًا إلى أجزاء أصغر حسب العدد أو الحجم لتتجاوز حدود البريد الإلكتروني أو WhatsApp، ثم اجمعها مجددًا بأداة دمج الملفات.
  • دمج الملفات (ضم الأجزاء)
    اجمع أجزاء الملف المقسّم (.001 و.002 أو part1 وpart2) لاستعادة الملف الأصلي بالترتيب الصحيح، مباشرة في متصفحك.
  • محوّل الخطوط (TTF وOTF وWOFF وEOT)
    حوّل الخطوط بين TTF وOTF وWOFF وEOT، وافتح ملفات WOFF2 أيضًا. واحصل على شيفرة CSS الخاصة بـ @font-face لموقعك.
  • تحويل TTF إلى WOFF
    حوّل خط TTF إلى WOFF لموقعك في ثوانٍ: ملفات أصغر بالأحرف نفسها، مع شيفرة CSS جاهزة لـ @font-face.
  • تحويل OTF إلى WOFF
    حوّل خط OpenType (OTF) إلى WOFF للمواقع مع الحفاظ على مخططات CFF وميزات الخط وتباعد الأحرف. يتضمن شيفرة CSS لـ @font-face.
  • تحويل WOFF إلى TTF
    أعد خط الويب WOFF إلى ملف TTF يمكنك تثبيته على Windows أو Mac واستخدامه في Word أو Photoshop أو Canva.
  • تحويل WOFF إلى OTF
    حوّل خط الويب WOFF إلى ملف OTF لتثبيته على جهازك أو استخدامه في تطبيقات التصميم، دون رفعه.
  • تحويل WOFF2 إلى TTF
    حوّل خط الويب WOFF2 (الصيغة الحديثة في Google Fonts) إلى TTF يمكنك تثبيته واستخدامه في Word أو Canva أو Photoshop.
  • تحويل WOFF2 إلى OTF
    حوّل خط الويب WOFF2 إلى ملف خط OTF يمكنك تثبيته على Windows أو Mac، دون رفعه إلى أي مكان.
  • تحويل WOFF2 إلى WOFF
    حوّل خط WOFF2 إلى WOFF للمتصفحات القديمة ومنشئي الرسائل والتطبيقات التي لا تقبل WOFF2. شيفرة CSS مرفقة.
  • تحويل TTF إلى EOT
    أنشئ خط ويب EOT من TTF لدعم الإصدارات القديمة جدًا من Internet Explorer (من 6 إلى 8)، مع شيفرة @font-face CSS المطابقة.
  • تحويل EOT إلى TTF
    استخرج خط TTF من ملف خط الويب EOT لتثبيته أو تحويله مرة أخرى. لا يُرفع أي شيء.
  • معاينة الخطوط واختبارها
    شاهد شكل الخط قبل تثبيته: نصك الخاص بعدة أحجام، والأبجدية ورموزها، مع حفظها كصورة PNG.
  • عارض معلومات الخط
    اقرأ كل ما في ملف الخط: الاسم والمصمم والترخيص والإصدار وعدد الحروف والمقاييس وميزات OpenType واللغات.
  • منشئ خطوط الويب (حزمة كاملة)
    حوّل خط TTF أو OTF إلى حزمة خطوط ويب جاهزة: WOFF وTTF وEOT اختياريًا وملف stylesheet.css وصفحة تجريبية في ملف ZIP واحد.
  • فاحص نوع الملف
    اعرف حقيقة أي ملف، حتى لو كان امتداده خاطئًا أو مفقودًا، واطّلع على تفاصيله: الحجم والأبعاد والصفحات والكاميرا وغيرها.

  • أداة إعادة الصياغة
    قل الشيء نفسه بكلمات جديدة: أعد صياغة المقالات والواجبات ورسائل البريد الإلكتروني بأسلوب عادي أو سلس أو رسمي أو بسيط أو إبداعي.

    الصق مقالًا أو فصلًا أو تقريرًا طويلًا واحصل على النقاط الرئيسية أو فقرة قصيرة أو ملخص في سطر واحد خلال ثوانٍ.

    صحّح الأخطاء الإملائية والنحوية وأخطاء الترقيم في النصوص الإنجليزية، أو احصل على قائمة بكل خطأ مع تصحيحه.
  • إعادة كتابة الجمل
    أعد كتابة جملة أو فقرة قصيرة بعدة طرق مختلفة، بالنبرة نفسها أو بنبرة أكثر رسمية أو ودية أو بساطة.
  • توسيع الجمل
    اجعل جملة أو ملاحظة قصيرة أطول بتفاصيل وشروح مفيدة، للواجبات ورسائل البريد الإلكتروني ونصوص المنتجات.

    اختصر الجمل والفقرات الطويلة لتناسب حدود الكلمات والتغريدات والرسائل القصيرة والملخصات، مع الحفاظ على الحقائق الأساسية.
  • كاتب الخاتمة
    الصق مقالك (أو موضوعه ونقاطه الرئيسية) واحصل على خاتمة قوية تلخّصه بكلمات جديدة.

البيانات الوصفية والخصوصية

اطّلع على التفاصيل المخفية في الصور وصور الذكاء الاصطناعي ومقاطع الفيديو والمستندات والملفات الصوتية وأزلها. عن هذه الأدوات: طريقة العمل والأدلة والأسئلة الشائعة.

  • مزيل البيانات الوصفية للذكاء الاصطناعي
    أزل بيانات EXIF وGPS وXMP وIPTC وبيانات اعتماد المحتوى وأوامر الذكاء الاصطناعي من الصور وصور الذكاء الاصطناعي. حتى 50 صورة دفعة واحدة.
  • منظّف البيانات الوصفية للفيديو
    أزل موقع GPS وطراز الكاميرا والتواريخ والعناوين والوسوم من فيديوهات MP4 وMOV وM4V وWebM وMKV دون إعادة الترميز.
  • فحص خصوصية الصور
    اعرف ما تكشفه الصورة قبل مشاركتها: موقع GPS واسمك والأرقام التسلسلية للجهاز والتواريخ وأوامر الذكاء الاصطناعي.
  • فاحص بيانات اعتماد المحتوى (C2PA)
    افحص صورة أو فيديو بحثًا عن بيانات اعتماد المحتوى (C2PA): التطبيق الذي أنشأه، والإجراءات عليه، ونوع مصدر الذكاء الاصطناعي، والجهة الموقِّعة.
  • عارض أوامر الذكاء الاصطناعي
    اقرأ الأمر والبذرة وأداة أخذ العينات والخطوات وقيمة CFG والنموذج المحفوظة في صور الذكاء الاصطناعي من Stable Diffusion وComfyUI وغيرها.
  • مقارنة الصور
    قارن بين صورتين بشريط تمرير قبل وبعد، وعرض للفروق على مستوى البكسل، وجدول بالبيانات الوصفية المختلفة.
  • منظّف البيانات الوصفية للمستندات
    أزل المؤلف والشركة وآخر من عدّل ورقم المراجعة والخصائص المخصصة من ملفات Word وExcel وPowerPoint وPDF.
