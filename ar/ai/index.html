الكتابة بالذكاء الاصطناعي

أداة إعادة الصياغة

قل الشيء نفسه بكلمات جديدة: أعد صياغة المقالات والواجبات ورسائل البريد الإلكتروني بأسلوب عادي أو سلس أو رسمي أو بسيط أو إبداعي.

تلخيص النصوص بالذكاء الاصطناعي

الصق مقالًا أو فصلًا أو تقريرًا طويلًا واحصل على النقاط الرئيسية أو فقرة قصيرة أو ملخص في سطر واحد خلال ثوانٍ.

المدقق النحوي

صحّح الأخطاء الإملائية والنحوية وأخطاء الترقيم في النصوص الإنجليزية، أو احصل على قائمة بكل خطأ مع تصحيحه.

إعادة كتابة الجمل

أعد كتابة جملة أو فقرة قصيرة بعدة طرق مختلفة، بالنبرة نفسها أو بنبرة أكثر رسمية أو ودية أو بساطة.

توسيع الجمل

اجعل جملة أو ملاحظة قصيرة أطول بتفاصيل وشروح مفيدة، للواجبات ورسائل البريد الإلكتروني ونصوص المنتجات.

اختصار الجمل

اختصر الجمل والفقرات الطويلة لتناسب حدود الكلمات والتغريدات والرسائل القصيرة والملخصات، مع الحفاظ على الحقائق الأساسية.

كاتب الخاتمة

الصق مقالك (أو موضوعه ونقاطه الرئيسية) واحصل على خاتمة قوية تلخّصه بكلمات جديدة.

تغيير نبرة النص

أعد كتابة رسالة أو بريد إلكتروني أو منشور بنبرة جديدة: رسمية أو ودية أو مهذبة أو واثقة أو مقنعة أو بسيطة أو مرحة.

إكمال الفقرات

توقفت في المنتصف؟ الصق فقرتك أو قصتك غير المكتملة وسيكملها الذكاء الاصطناعي بالأسلوب والنبرة واللغة نفسها.

كاتب المقالات

اكتب مقالًا عن أي موضوع للمدرسة أو الكلية أو الجامعة: تفسيري أو جدلي أو سردي وغيرها، من 300 إلى 800 كلمة.

كاتب الفقرات

اكتب فقرة منظمة جيدًا عن أي موضوع، بجملة افتتاحية وأدلة داعمة وسطر ختامي، بالنبرة التي تحتاجها.

كاتب القصص

حوّل فكرة إلى قصة قصيرة أصلية: قصص أطفال ذات عبرة، أو مغامرة، أو مضحكة، أو غموض، أو عائلية، أو حكايات خيالية.

كاتب القصائد

اكتب قصيدة أصلية عن أي موضوع: مقفّاة، أو شعرًا حرًا، أو قصيدة أكروستيك، أو هايكو، أو قصيدة للأطفال، بالمزاج الذي تختاره.

كاتب الرسائل والطلبات

اكتب الطلبات والرسائل بالصيغة الصحيحة: طلب إجازة، أو شكوى، أو طلب، أو استقالة، أو توصية، أو رسالة شخصية.

منشئ المخططات

خطّط لمقالك أو تدوينتك أو خطابك أو تقريرك أو عرضك التقديمي بمخطط مرقّم للأقسام والنقاط الفرعية.

منشئ الأطروحة الرئيسية

احصل على عبارات أطروحة واضحة ومحددة لمقالك أو موضوع بحثك: جدلية أو تحليلية أو تفسيرية أو مقارنة.

كاتب المقدمة

اكتب فقرة افتتاحية تجذب الانتباه لمقال أو تدوينة أو خطاب أو تقرير أو ورقة بحثية.

منشئ أفكار التدوينات

لن تنفد أفكارك للكتابة بعد اليوم: احصل على أفكار تدوينات بعناوين جذابة وخطة من سطر واحد لأي مجال.

منشئ العناوين

احصل على عناوين جذابة لتدوينة أو فيديو YouTube أو مقال أو كتاب أو منتج أو سطر موضوع لبريد إلكتروني.

ترجمة النصوص بالذكاء الاصطناعي

ترجم النص الملصق بين الإنجليزية والأردية بالحروف اللاتينية والعربية والهندية والصينية وغيرها، مع الحفاظ على الأسماء والأرقام وفواصل الأسطر.

كاتب رسائل البريد الإلكتروني

اكتب رسالة بريد إلكتروني واضحة مع سطر الموضوع في ثوانٍ: عمل، أو طلب وظيفة، أو طلب إجازة، أو متابعة، أو شكوى، أو شكر.

كاتب الردود على البريد الإلكتروني

الصق رسالة وصلتك واحصل على رد جاهز: قبول، أو اعتذار مهذب، أو إجابة عن الأسئلة، أو طلب تفاصيل.

كاتب خطاب التقديم

الصق إعلان الوظيفة وبياناتك واحصل على خطاب تقديم يربط مهاراتك بالوظيفة، للخريجين الجدد وأصحاب الخبرة.

منشئ نقاط السيرة الذاتية

حوّل ما أنجزته في عملك إلى نقاط قوية في سيرتك الذاتية تبدأ بأفعال عمل وتُظهر النتائج.

منشئ نبذة LinkedIn

اكتب قسم «نبذة عني» في ملفك على LinkedIn من بضعة أسطر عن عملك ومهاراتك وأهدافك.

منشئ أوصاف المنتجات

اكتب أوصاف منتجات تبيع، لمتجرك الإلكتروني أو قوائم المنصات أو صفحة Facebook أو كتالوج WhatsApp.

منشئ الشعارات النصية

احصل على شعارات وعبارات جذابة لنشاطك التجاري أو متجرك أو علامتك أو حملتك أو فعاليتك، قصيرة وسهلة التذكر.

منشئ أسماء الأنشطة التجارية

احصل على أفكار أسماء لمتجرك أو شركتك الناشئة أو علامتك أو نشاطك عبر الإنترنت: عصرية أو كلاسيكية أو وصفية أو بطابع محلي.

منشئ تعليقات Instagram

اكتب تعليقات Instagram تلفت الانتباه لصورتك أو مقطع Reels أو منشور منتجك، مع رموز تعبيرية ووسوم إن أردت.

منشئ الوسوم (الهاشتاغ)

احصل على وسوم مناسبة لـ Instagram أو TikTok أو YouTube أو LinkedIn أو X، تمزج بين الوسوم الشائعة والمتخصصة، جاهزة للصق.

عنوان ووصف YouTube

احصل على أفكار عناوين لـ YouTube ووصف جاهز للفيديو ببداية قوية ودعوة للاشتراك ووسوم.

منشئ نصوص إعلانات Facebook

اكتب نصوص إعلانات Facebook وInstagram: العنوان والنص الأساسي والوصف والزر، في ما يصل إلى 3 نسخ لاختبارها.

منشئ الأسئلة الشائعة

الصق تفاصيل عن نشاطك أو منتجك أو صفحتك واحصل على الأسئلة التي يطرحها العملاء مع إجاباتها، جاهزة لموقعك.

كاتب الردود على المراجعات

ردّ على مراجعات Google أو Facebook أو المتاجر الإلكترونية بالطريقة الصحيحة: اشكر العملاء الراضين وهدّئ غير الراضين بلباقة.

كاتب الخطابات

اكتب خطابًا لحفل مدرسي أو 14 أغسطس أو حفل وداع أو ترحيب أو زفاف أو تكريم أو فعالية عمل، مدته من 2 إلى 8 دقائق.

كاتب رسائل الاعتذار

اعتذر بالطريقة الصحيحة: رسالة اعتذار صادقة أو رسالة قصيرة إلى مديرك أو معلمك أو عميلك أو صديقك أو عائلتك.

كاتب رسائل الشكر

اكتب رسالة شكر دافئة أو رسالة WhatsApp أو بريدًا إلكترونيًا على هدية أو مساعدة أو مقابلة عمل أو لمعلم أو في زفاف.

صياغة دعوات الزفاف

اكتب نص بطاقة الزفاف: ليلة الحناء والزفة وعقد القران والوليمة، بأسلوب تقليدي أو عصري، باسم الوالدين أو العروسين.

منشئ تهاني العيد

احصل على تهانٍ أصلية بعيد الفطر وعيد الأضحى للعائلة والأصدقاء والعملاء والزملاء، جاهزة للإرسال عبر WhatsApp.

كاتب التدوينات

اكتب تدوينة أو مقالة كاملة من موضوع: العنوان والمقدمة والأقسام بعناوينها والنصائح والخاتمة.

الشرح بكلمات بسيطة

الصق موضوعًا أو فقرة صعبة واحصل على شرح بكلمات بسيطة جدًا، كأن عمرك 10 سنوات، أو كأنك طالب أو جديد في المجال.

منشئ الاختبارات بالذكاء الاصطناعي

أنشئ اختبارًا مع الإجابات من موضوع أو نص ملصق: اختيار من متعدد أو صح وخطأ أو أسئلة قصيرة، للفصل أو المراجعة.

منشئ الأوصاف التعريفية (Meta)

اكتب أوصافًا تعريفية لتحسين محركات البحث (SEO) من 140 إلى 155 حرفًا لصفحاتك، مع الكلمة المفتاحية قرب البداية ودعوة لاتخاذ إجراء.

منشئ منشورات LinkedIn

اكتب منشورًا على LinkedIn عن إنجاز أو وظيفة جديدة أو دروس مستفادة أو توظيف أو إطلاق منتج، بسطر أول قوي.

كاتب إعلانات العقارات

اكتب إعلانًا عقاريًا لمنزل أو قطعة أرض أو شقة أو محل للبيع أو الإيجار، بالمرلة أو الكنال أو القدم المربعة، جاهزًا لمواقع العقارات.

كاتب نصوص الفيديو

اكتب نصًا لفيديو YouTube أو مقطع قصير على Reels أو TikTok أو Shorts: افتتاحية جاذبة والنقاط الرئيسية ودعوة لاتخاذ إجراء.
