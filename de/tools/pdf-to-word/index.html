PDF in Word

Wandeln Sie ein PDF in ein bearbeitbares Word-Dokument (DOCX) um – auch gescannte PDFs auf Englisch oder Urdu.

× Hilfe schließen

So nutzen Sie „PDF in Word“

  1. Wählen Sie eine Datei auf Ihrem Gerät aus.
  2. Prüfen Sie die Optionen und starten Sie die Umwandlung.
  3. Laden Sie die fertige Datei herunter.

Was macht dieses Tool?

Text-PDFs: Der markierbare Text wird Absatz für Absatz in die DOCX-Datei übernommen. Gescannte PDFs: Setzen Sie das Häkchen bei „Gescanntes PDF“, dann wird der Text per OCR auf Englisch, Urdu oder in beiden Sprachen erkannt. Tabellen, Bilder und das Seitenlayout werden nicht nachgebaut.

BeispielText-PDF oder Scan → bearbeitbare DOCX-Datei

Gut zu wissen

Welche Grenzen gibt es?

Wenn das Aussehen genau erhalten bleiben soll und Sie nur wenige Wörter ändern möchten, verwenden Sie stattdessen den PDF-Editor.

Unterstützt werden Eingaben bis 15 MB · 150 Seiten.

Wird meine Datei hochgeladen?

Nein. Der Code des Tools wird heruntergeladen; Ihre Datei oder Eingabe wird zur Umwandlung nicht an einen Server gesendet. Wenn Sie den Browser schließen, wird die Verarbeitung beendet.

Wie lange dauert es?

Text und kleine Eingaben werden meist schnell verarbeitet. PDFs, Bilder und Audio dauern je nach Größe, Codec und Geschwindigkeit Ihres Geräts länger.

Behält „PDF in Word“ meine Formatierung und Schriftarten bei?

Es übernimmt die Wörter und Absätze, nicht das genaue Aussehen: Tabellen, Bilder, Schriftarten und das Seitenlayout werden nicht nachgebaut. Wenn Sie nur wenige Wörter ändern und die Seite genau so behalten möchten, wie sie ist, verwenden Sie den PDF-Editor, der den Text in der Originalschrift des PDFs bearbeitet.

Kann ich ein gescanntes PDF in Word umwandeln?

Ja. Setzen Sie das Häkchen bei „Gescanntes PDF (Text per OCR erkennen)“ und wählen Sie Englisch, Urdu oder Urdu + Englisch. Ein sauberer, gerader Scan liefert das beste Ergebnis.

Funktioniert es auf dem Handy, Mac oder Laptop?

Ja. Es läuft im Browser auf Android, iPhone, Windows und Mac, ohne Installation und ohne Anmeldung. Unterstützt werden PDFs bis 15 MB und 150 Seiten.
