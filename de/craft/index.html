Was Sie bekommen

Jedes Element ist eine HTML-Datei, in der CSS und JavaScript bereits enthalten sind: keine Bibliotheken, kein Build-Schritt, nichts zu installieren (Studio-Elemente mit Fotos haben zusätzlich einen img-Ordner mit kostenlosen CC0-Fotos). Öffnen Sie die Datei, ändern Sie Texte und Farben und binden Sie sie in Ihre Website ein.

Nutzen Sie die Elemente in eigenen Projekten und in Projekten Ihrer Kunden; die Lizenz passt auf eine Seite. Die FAQ beantworten die üblichen Fragen, und das Änderungsprotokoll zeigt, was wann hinzugekommen ist.
