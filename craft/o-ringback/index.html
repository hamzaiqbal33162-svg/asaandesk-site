How it works

  1. Press the green call button; the avatar rings, then the call connects and a timer starts
  2. The waveform reads out the code and each digit appears in the captions; Repeat plays it again
  3. Type or paste the four digits; backspace and the arrow keys move between boxes
  4. A right code ends the call, flattens the wave into a drawn check and throws confetti
  5. A wrong code shakes the boxes; hang up any time with the red button and call again

About

An emerald call panel for people who prefer a phone call to a text message. Press the green button and the line rings, connects with a live call timer, and a coral waveform speaks the code while each digit pops up as a caption. Type the four digits and the waveform flattens into a line that draws itself into a check.
