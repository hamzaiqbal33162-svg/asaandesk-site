How it works

  1. Type, paste or autofill the demo code; backspace and arrow keys move between cells
  2. Each cell flips over and turns mint as soon as it gets a digit
  3. When all four are filled the code is checked
  4. A right code runs a wave through the cells and the lock badge becomes a check
  5. A wrong code turns the cells rose, shakes them and clears them

About

A 4-digit one-time code field made of frosted glass over slowly drifting colour blobs. Every digit flips its cell over to a fresh mint colour, and a right code sends a wave through the cells and turns the lock badge into a check. Good for login checks, two-step verification and email confirmation.

Use it in your site

Press Copy code or Download: it is one HTML file with its CSS and JavaScript inside and no outside files. Open it in a browser, or copy its parts into your page. Add ?theme=dark or ?theme=light to the address to force a theme.
