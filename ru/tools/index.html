    Конвертируйте ZIP-файл в TAR.GZ (или .tgz) в браузере — привычный формат для серверов Linux, загрузки в cPanel и исходного кода.

    Конвертируйте архив TAR в ZIP-файл, который открывается одним касанием на Windows, Mac, Android и iPhone, без загрузки на сервер.

    Сожмите архив TAR в TAR.GZ (или .tgz) с помощью GZIP прямо в браузере, чтобы он стал намного меньше для загрузки или резервной копии.
  • TAR.GZ в ZIP
    Конвертируйте файл TAR.GZ в ZIP, чтобы он открывался на любом компьютере с Windows или телефоне. Папки, имена и даты сохраняются; ничего не загружается на сервер.
  • TAR.GZ в TAR
    Снимите сжатие GZIP с файла TAR.GZ или TGZ и получите обычный архив TAR — прямо в браузере.
  • TGZ в ZIP
    Конвертируйте архив TGZ в ZIP в браузере, чтобы он открывался на Windows, Mac и телефонах без дополнительных приложений.

    Превратите файл .gz в ZIP. Одиночный сжатый файл попадает в ZIP как есть, а из .tar.gz извлекаются все файлы.

  • Сжатие GZIP (создать файл .GZ)
    Сожмите любой файл в .gz с помощью GZIP прямо в браузере. Выберите быстрое или максимальное сжатие; имя файла сохраняется внутри.
  • Открыть файл GZ (Gunzip)
