Kebijakan Privasi

Terakhir diperbarui: 27 November 2026

AsaanDesk (asaandesk.com) adalah situs berisi alat online gratis. Kami menggunakan data sesedikit mungkin. Halaman ini menjelaskan apa yang terjadi.

1. Sebagian besar alat: file Anda tetap di perangkat Anda

Alat PDF, gambar, audio, video, teks, dan kalkulator berjalan di dalam browser Anda. File Anda tidak diunggah ke server AsaanDesk, dan kami tidak dapat melihat atau menyimpannya.

2. Alat yang menggunakan server

  • Minta Tanda Tangan: PDF yang Anda kirim untuk ditandatangani disimpan di server AsaanDesk (Cloudflare) paling lama 7 hari agar penanda tangan dapat membukanya, lalu dihapus secara otomatis. Setelah ditandatangani, file aslinya dihapus. Anda dapat menghapusnya kapan saja dari halaman status. Bagian rahasia tautan hanya disimpan sebagai hash.
  • API Anggota Pembuat Kartu Identitas (hanya jika Anda membuat ruang kerja API): data anggota yang dikirim oleh Anda atau software Anda (nama, detail, dan foto) disimpan di server AsaanDesk (Cloudflare) sampai Anda menghapusnya atau menghapus seluruh ruang kerja. Hanya kunci API Anda yang dapat melihatnya, dan kami menyimpan kunci tersebut hanya sebagai hash. Tanpa API, desain dan data anggota hanya tersimpan di browser Anda.
  • Sinkronisasi cloud Pemindai Dokumen (hanya jika Anda mengaktifkannya): halaman Pindaian Saya (gambar), nama, folder, tag, dan teks yang dikenali disimpan di server AsaanDesk (Cloudflare) agar Anda bisa melihatnya di perangkat lain dengan kunci sinkronisasi Anda. Kami menyimpan kunci sinkronisasi hanya sebagai hash; Anda dapat menggunakan “Hapus semua dari cloud” kapan saja. Jika sinkronisasi nonaktif, pindaian hanya tersimpan di browser Anda.
  • Halaman Web ke PDF: server kami membuka tautan yang Anda berikan dan mengirimkan teks halaman tersebut kembali ke browser Anda. Tautan dan halamannya tidak disimpan.
  • Alat AI (saat AI Online aktif): teks yang diekstrak dari PDF (bukan filenya) dikirim ke OpenAI untuk mendapatkan jawaban dan tidak disimpan. Saat AI Online nonaktif, alat AI memakai AI bawaan Chrome di perangkat, dan teks tidak pernah meninggalkan perangkat Anda.

Untuk menerapkan batas harian, kami menyimpan hash alamat IP Anda (yang berubah setiap hari) dan jumlah penggunaan hari itu. Alamat IP Anda yang sebenarnya tidak disimpan.

Untuk menampilkan berapa orang yang sedang menggunakan alat dan berapa kunjungan hari ini, browser Anda mengirimkan ke server AsaanDesk sebuah id acak yang dibuat untuk tab tersebut (disimpan hanya di session storage tab itu) beserta nama alatnya sekitar setiap 45 detik selama halaman terbuka dan terlihat; id ini disimpan sekitar 90 detik untuk hitungan langsung dan, untuk hitungan kunjungan hari itu (waktu Pakistan), sampai hari berakhir, lalu dihapus dalam tiga hari; tidak ada cookie yang digunakan, dan tidak ada data pribadi (seperti alamat IP Anda) yang disimpan.

3. Google Drive

Jika Anda mengklik “Pilih dari Google Drive”, jendela milik Google akan terbuka. AsaanDesk hanya meminta izin Google Drive drive.file, artinya hanya file yang Anda pilih sendiri. File tersebut diunduh langsung ke browser Anda agar alat dapat memprosesnya. Kami tidak melihat file lain di Drive Anda, tidak menyimpan file Anda di server kami, dan tidak membagikan atau menjual data pengguna Google maupun menggunakannya untuk iklan. Penggunaan data yang diterima AsaanDesk dari Google API mematuhi Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Penggunaan Terbatas. Anda dapat mencabut izin Google kapan saja di myaccount.google.com/permissions.

4. Cuaca

Dengan izin Anda, widget cuaca mengirimkan lokasi Anda (atau kota yang Anda pilih) ke Open-Meteo untuk menampilkan cuaca. AsaanDesk tidak menyimpannya.

5. Penyimpanan browser dan cookie

Beberapa alat (seperti pembuat CV atau faktur) menyimpan apa yang Anda ketik di penyimpanan lokal browser Anda sendiri agar pekerjaan Anda tidak hilang saat halaman ditutup. Data ini tidak dikirim ke server kami. AsaanDesk sendiri tidak memasang cookie pelacak; mitra iklan dapat memasang cookie seperti dijelaskan di bagian 6.

Untuk mengetahui halaman mana yang digunakan, kami menghitung tayangan halaman dengan Cloudflare Web Analytics. Layanan ini tidak memasang cookie, tidak mengidentifikasi Anda, dan tidak mengikuti Anda di situs web lain; yang dicatat adalah alamat halaman, situs perujuk, jenis browser, dan kecepatan pemuatan. File Anda dan apa yang Anda ketik di alat tidak pernah termasuk di dalamnya.

6. Iklan (Google AdSense)

Agar alat tetap gratis, AsaanDesk dapat menampilkan iklan yang disajikan oleh Google AdSense dan mitra iklan Google lainnya.

  • Vendor pihak ketiga, termasuk Google, menggunakan cookie untuk menayangkan iklan berdasarkan kunjungan sebelumnya pengguna ke situs ini atau situs web lain.
  • Penggunaan cookie iklan oleh Google memungkinkan Google dan mitranya menayangkan iklan kepada Anda berdasarkan kunjungan Anda ke AsaanDesk dan/atau situs lain di Internet.
  • Anda dapat menolak iklan yang dipersonalisasi dengan membuka Setelan Iklan Google. Anda juga dapat menolak penggunaan cookie oleh sebagian vendor pihak ketiga untuk iklan yang dipersonalisasi di www.aboutads.info/choices (dan youronlinechoices.eu di Eropa).
  • Jika Anda berada di Wilayah Ekonomi Eropa, Inggris Raya, atau Swiss, kami meminta persetujuan Anda sebelum iklan yang dipersonalisasi ditampilkan, dan Anda dapat mengubah pilihan Anda kapan saja melalui pesan privasi di situs.
  • Pelajari lebih lanjut di Cara Google menggunakan informasi dari situs atau aplikasi yang menggunakan layanannya dan halaman cookie iklan Google.

Iklan tidak pernah menerima file Anda atau apa yang Anda ketik di alat.

7. Anak-anak

AsaanDesk tidak secara khusus ditujukan untuk anak-anak, dan kami tidak dengan sengaja mengumpulkan data anak-anak.
