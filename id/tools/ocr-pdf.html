OCR PDF (Bisa Dicari)

Ubah PDF hasil pindaian dalam bahasa Inggris atau Urdu menjadi PDF yang teksnya bisa dicari dan disalin.

Membaca bahasa Inggris, Urdu, atau keduanya: pilih bahasa dokumen. Pindaian yang bersih dan lurus memberi hasil lebih baik. Biarkan tab ini terbuka selama pemrosesan berat. Batal akan menghentikan proses.

Cara menggunakan OCR PDF (Bisa Dicari)

  1. Pilih file dari perangkat Anda, letakkan di sini, atau tempel tautan file.
  2. Periksa opsi lalu tekan Konversi.
  3. Unduh file yang sudah jadi.

Apa fungsi alat ini?

Membaca teks di setiap halaman dan menambahkan lapisan teks tersembunyi di atas pindaian. Tampilan halaman tetap sama, tetapi bisa dicari dengan Ctrl+F dan disalin.

Contohscan.pdf → scan-ocr.pdf (bisa dicari)

Apa saja batasannya?

Membaca bahasa Inggris, Urdu, atau keduanya: pilih bahasa dokumen. Pindaian yang bersih dan lurus memberi hasil lebih baik.

Input hingga 50 MB · 50 halaman didukung.

Apakah file saya diunggah?

Tidak. Yang diunduh adalah kode alatnya; file atau input Anda tidak dikirim ke server untuk dikonversi. Menutup browser akan menghentikan prosesnya.

Berapa lama prosesnya?

Teks dan input kecil biasanya diproses dengan cepat. PDF, gambar, dan audio memerlukan waktu lebih lama, tergantung ukuran, codec, dan kecepatan perangkat Anda.

Bahasa apa saja yang bisa dibaca?

Inggris, Urdu, atau keduanya dalam dokumen yang sama: pilih bahasa dokumen sebelum mulai. Hingga 50 halaman dan 50 MB.

Apakah tampilan pindaian berubah setelah OCR?

Tidak. Halaman tampak persis sama; hanya lapisan teks tersembunyi yang ditambahkan, sehingga Anda bisa mencarinya dengan Ctrl+F dan menyalin teksnya.

Bisakah saya mendapatkan teksnya sebagai file Word?

Bisa: gunakan PDF ke Word dengan opsi "PDF hasil pindaian" dicentang untuk mendapatkan DOCX yang bisa diedit.
