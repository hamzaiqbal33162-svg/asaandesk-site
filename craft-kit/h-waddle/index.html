    Trouble getting in?

    Quick answers from the Waddle help desk.

    I forgot my password

    Use Reset password. Pebble posts a 6-digit code to your email; it works once, for 10 minutes.

    The code never arrived

    Check spam and promotions, then press Resend when the timer ends. In this demo the code is always 482 913.

    An admin removed me from a huddle

    Ask any admin to send a new invite from Settings, then Members. Your own photos stay in your account.

    Is this a real service?

    No. Waddle is a free Chill & Craft template. Nothing you type leaves this page; demo accounts live in your browser only.
