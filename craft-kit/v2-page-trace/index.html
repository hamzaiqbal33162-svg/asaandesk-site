Parcel API guide

Track your first parcel

Updated 18 November 2026 · for shops in Pakistan

Overview

The Tracklet API lets your shop create parcels, follow them across Pakistan and hear back the moment they are delivered. Every call is a small JSON request over HTTPS.

This guide takes a few minutes. By the end you will have a test key, a tracked parcel and a webhook that tells you when it arrives.

Set up

There is nothing to install. Any HTTP client works; every request goes to one base address and carries a version header:

BASE    https://api.tracklet.test/v1
HEADER  Tracklet-Version: 2026-11

Authenticate

Requests are signed with a secret key in the Authorization header. Keep it on your server; never put it in a web page or an app.

Get a key

Open Settings, then API keys, and press New test key. Test keys start with tk_test_ and only ever touch the sandbox.

Tip: rotate keys from the same screen. Old keys keep working for 24 hours, so nothing breaks in the middle of a delivery.

Make a test call

curl https://api.tracklet.test/v1/ping \
  -H "Authorization: Bearer tk_test_51Hx"

A healthy key answers with {"ok": true} and the name of your shop.

Track a parcel

Each parcel gets a tracking number when you create it. Use that number to ask where it is at any time.

Request

GET /v1/parcels/TK-48213-LHE
Authorization: Bearer tk_test_51Hx

Response

{
  "id": "TK-48213-LHE",
  "status": "out_for_delivery",
  "city": "Karachi",
  "eta": "2026-11-21T15:00:00+05:00",
  "events": 6
}

Statuses move from created to picked_up, in_transit, out_for_delivery and delivered. A parcel can also end as returned.

Webhooks

Instead of asking again and again, let us call you. Add an HTTPS address under Settings and choose the events you want.

Events

  • parcel.picked_up when the rider collects it
  • parcel.delivered with the name of whoever signed
  • parcel.failed_attempt with the reason
  • parcel.returned when it comes back to you

Each event carries the full parcel, so you rarely need a second call.

Retries

If your server does not answer with a 2xx code within 10 seconds, we try again after 1, 5, 30 and 120 minutes. After the fifth miss the event waits in your dashboard until you replay it.

Errors

CodeWhat it means
400A field is missing or has the wrong type.
401The key is wrong, or it was revoked.
404No parcel has that tracking number.
429Too many requests; see Limits below.

Limits

Test keys allow 30 requests a minute and live keys 300. Every response says what is left in the Tracklet-Remaining header.

Expecting a rush for Eid or a big sale? Ask support a week ahead and we will raise your limit for those days.
