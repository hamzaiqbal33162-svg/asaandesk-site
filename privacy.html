Privacy Policy

Last updated: 7 November 2026

AsaanDesk (asaandesk.com) free online tools ki website hai. Hum kam se kam data istemal karte hain. Ye page batata hai ke kya hota hai.

1. Zyada tar tools: file aap ke device par rehti hai

PDF, image, audio, video, text aur calculator tools aap ke browser ke andar chalte hain. Aap ki file AsaanDesk ke server par upload nahi hoti aur hum use dekh ya save nahi kar sakte.

2. Jo tools server istemal karte hain

  • Request Signature: jo PDF aap sign karwane ke liye bhejte hain, wo AsaanDesk ke server (Cloudflare) par zyada se zyada 7 din rehti hai taa ke sign karne wala use khol sake, phir khud delete ho jati hai. Sign hone par asal file mita di jati hai. Aap status page se kisi bhi waqt delete kar sakte hain. Links ke secret hisse sirf hash ki shakal mein save hote hain.
  • ID Card Maker ka Members API (sirf agar aap API workspace banayein): aap ke software ya aap ke bheje hue members (naam, details aur tasveerein) AsaanDesk ke server (Cloudflare) par save hote hain jab tak aap unhein ya poora workspace delete na karein. Unhein sirf aap ka API key dekh sakta hai, jo hum hash ki shakal mein rakhte hain. Bina API ke, designs aur members sirf aap ke browser mein rehte hain.
  • Document Scanner ka Cloud sync (sirf agar aap on karein): My Scans ke pages (tasveerein), naam, folder, tags aur parha hua text AsaanDesk ke server (Cloudflare) par save hote hain, taa ke aap sync key se doosre device par dekh sakein. Sync key hum sirf hash ki shakal mein rakhte hain; aap kabhi bhi “Cloud se sab delete” kar sakte hain. Sync band ho to scans sirf aap ke browser mein rehte hain.
  • Webpage to PDF: aap ka diya hua link hamara server kholta hai aur page ka text aap ke browser ko bhejta hai. Link ya page save nahi hota.
  • AI tools (jab Online AI on ho): PDF se nikla hua text (file nahi) jawab ke liye OpenAI ko bheja jata hai aur save nahi kiya jata. Jab Online AI band ho, AI tools Chrome ke apne on-device AI se chalte hain aur text aap ke device se bahar nahi jata.

Rozana hadd lagane ke liye hum aap ke IP address ka ek hash (jo har din badal jata hai) aur us din ki ginti rakhte hain. Asal IP address save nahi hota.

3. Google Drive

Agar aap “Google Drive se chunein” dabate hain, to Google ki apni window khulti hai. AsaanDesk Google Drive ki sirf drive.file ijazat maangta hai, yani sirf wohi file jo aap khud chunte hain. Wo file seedha aap ke browser mein download hoti hai taa ke tool us par kaam kar sake. Hum aap ki Drive ki doosri files nahi dekhte, aap ki file ko apne server par save nahi karte, aur Google user data ko kisi ke saath share, bech ya advertising ke liye istemal nahi karte. AsaanDesk ka Google API se mila data ka istemal Google API Services User Data Policy aur us ki Limited Use shartein maanta hai. Aap Google ki ijazat kabhi bhi myaccount.google.com/permissions se hata sakte hain.

4. Mausam

Mausam ka widget aap ki ijazat se aap ki location (ya aap ka chuna hua shehar) Open-Meteo ko bhejta hai taa ke mausam dikhaye. AsaanDesk ise save nahi karta.

5. Browser storage aur cookies

Kuch tools (jaise CV ya invoice maker) aap ka likha hua aap ke apne browser ke local storage mein rakhte hain taa ke page band hone par kaam zaya na ho. Ye hamare server par nahi jata. Hum tracking ya advertising cookies istemal nahi karte.

6. Bachche

AsaanDesk khaas tor par bachchon ke liye nahi hai aur hum jaan boojh kar bachchon ka data jama nahi karte.
