How it works

Data sizes are counted in bytes (a file of 2 GB), but connection speeds in bits per second (a 20 Mbit/s plan), and one byte is 8 bits. That factor of 8 is why a 20 Mbit/s line downloads only 2.5 megabytes each second. The first tab turns a file size and a speed into a time, and shows the same file at other common speeds. The second shows one amount of data in every unit. The third works out the bandwidth and the monthly data a website needs from its page views and average page size, with a safety factor for busy hours. The last turns a hosting plan's monthly data into the steady speed it equals, or the other way round.

The formula

  • 1 byte = 8 bits; decimal prefixes: 1 kB = 1,000 B, 1 MB = 1,000,000 B, 1 GB = 10⁹ B, 1 TB = 10¹² B (the same for kb, Mb, Gb, Tb in bits)
  • Binary prefixes: 1 KiB = 1,024 B, 1 MiB = 1,024² B, 1 GiB = 1,024³ B, 1 TiB = 1,024⁴ B
  • Transfer time = data in bits ÷ speed in bits per second
  • Website bandwidth (bit/s) = page views per second × page size in bytes × 8; with the safety factor, multiply by it
  • Data per month = bytes per second × 2,629,800 seconds (one month = 365.25 ÷ 12 = 30.4375 days)

A worked example

A 500 MB file over a 5 Mbit/s connection: 500 MB × 8 = 4,000 Mb, and 4,000 Mb ÷ 5 Mbit/s = 800 seconds, which is 13 minutes 20 seconds. At 50 Mbit/s the same file takes 1 minute 20 seconds.

Sources

  • NIST: prefixes for binary multiples (KiB, MiB, GiB)
  • NIST: SI prefixes (kilo, mega, giga, tera)
  • Data-rate units: bit per second and byte per second

Questions

Why is my download slower than my plan's speed?

Plans are sold in megabits per second, and file sizes are in megabytes, so divide the speed by 8 first: 100 Mbit/s moves at most 12.5 MB a second. Network protocols, Wi-Fi and other devices on the line also take a share, usually 5% to 10% or more; set it under More options.

What is the difference between GB and GiB?

A gigabyte (GB) is 1,000,000,000 bytes; a gibibyte (GiB) is 1,073,741,824 bytes (1,024³), about 7.4% more. Drive makers and networks use GB, while many computers show file sizes in GiB but label them GB, which is why a new 1 TB drive shows about 931 GB.

What safety factor should a website use?

Traffic comes in bursts, so plan for more than the average. A factor of 2 is a common starting point; sites with sudden peaks (sales, news, launches) often use 3 to 5.

How is a month counted?

As an average month of 30.4375 days (365.25 days ÷ 12), or 2,629,800 seconds.
