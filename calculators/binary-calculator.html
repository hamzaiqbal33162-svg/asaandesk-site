What this binary calculator does

A binary calculator works with numbers written in base 2, the number system that uses only the digits 0 and 1. This one does four jobs: it adds, subtracts, multiplies and divides two binary numbers; it combines them bit by bit with AND, OR and XOR; it converts binary to decimal; and it converts decimal to binary, fractions included. Every answer comes with the steps, so you can check homework or learn the method rather than just copy a result.

In ordinary decimal (base 10) each place is worth ten times the place to its right: ones, tens, hundreds. Binary works the same way with a factor of two: ones, twos, fours, eights, sixteens and so on. Computers use it because a circuit only has to tell two states apart, on or off, and every number, letter, picture and sound is stored as long rows of these bits.

How to use the binary calculator

  • Choose a tab: Calculate, Binary to decimal or Decimal to binary.
  • Calculate: type the First binary number (the page opens with 101101), pick an Operation (+ Add, − Subtract, × Multiply, ÷ Divide (with remainder), AND, OR or XOR) and type the Second binary number (1011 to start). A minus sign is allowed for add, subtract, multiply and divide.
  • Binary to decimal: type the Binary number (110010 to start). You may use a point for a fraction, such as 101.01, and a minus sign.
  • Decimal to binary: type the Decimal number (100 to start). Whole numbers, negative numbers and decimals such as 10.5 all work.
  • Spaces and underscores between digits are ignored, so 1010 1010 and 1010_1010 are read as 10101010, and a leading 0b (as in 0b1011) is accepted. Numbers can be as long as you like; the maths uses exact whole-number arithmetic, not rounded floating point.

Understanding the results

  • The headline gives the answer in binary: Sum, Difference, Product, Quotient, or the AND, OR or XOR of the two numbers.
  • In decimal and Worked in decimal repeat the sum in everyday numbers (45 + 11 = 56 for the opening example), which is the quickest way to check a binary answer.
  • In hexadecimal and In octal give the same value in base 16 and base 8. For the opening example, 111000 is 38 in hex and 70 in octal.
  • Division shows the Quotient in binary and the Remainder, both again in decimal, and, when the division is not exact, the Exact quotient with the digits after the point and which block of them repeats.
  • A negative answer keeps its minus sign (−101 for −5) and also shows its two's complement in the smallest of 8, 16, 32, 64 or 128 bits that fits, labelled as how a computer stores it.
  • AND, OR and XOR add a Bit by bit table that lines the two numbers up with the answer under them.
  • The converters show the steps: the place values that add up to the decimal answer, or a Dividing by 2 table of quotients and remainders. Up to 32 binary digits after the point are worked out, and a note tells you when they repeat forever.

Hex and octal are shorthand for binary. Split a binary number into groups of four digits from the right and each group is one hex digit: 1011 0111 is B and 7, so 10110111 = B7. Groups of three give octal: 10 110 111 is 2, 6 and 7, so 267.

How to convert binary to decimal and decimal to binary, with steps

Binary to decimal: write the place value over each digit, starting with 1 on the right and doubling as you go left, then add the places that hold a 1. For 10110111 the calculator shows 1×2^7 + 0×2^6 + 1×2^5 + 1×2^4 + 0×2^3 + 1×2^2 + 1×2^1 + 1×2^0, which is 128 + 32 + 16 + 4 + 2 + 1 = 183. Digits after the point are worth halves, quarters and eighths, so 1101.101 = 8 + 4 + 1 + 0.5 + 0.125 = 13.625.

Decimal to binary: divide by 2, write down the remainder (0 or 1), and keep dividing the quotient until it reaches 0. Then read the remainders from the bottom up. This is the Dividing by 2 table for 156:

  • 156 ÷ 2 = 78, remainder 0
  • 78 ÷ 2 = 39, remainder 0
  • 39 ÷ 2 = 19, remainder 1
  • 19 ÷ 2 = 9, remainder 1
  • 9 ÷ 2 = 4, remainder 1
  • 4 ÷ 2 = 2, remainder 0
  • 2 ÷ 2 = 1, remainder 0
  • 1 ÷ 2 = 0, remainder 1, so reading upward 156 = 10011100

For a decimal fraction, convert the whole part as above, then multiply the part after the point by 2 again and again; each whole part you get (0 or 1) is the next binary digit. For 10.625: 0.625 × 2 = 1.25 gives 1, 0.25 × 2 = 0.5 gives 0, 0.5 × 2 = 1 gives 1, so 10.625 = 1010.101.

Some fractions never end in binary. 0.1 gives 0.2, 0.4, 0.8, 1.6, 1.2, 0.4 … and the block 0011 repeats forever, so 0.1 is 0.000110011… in base 2. That is why computers that store numbers in binary floating point cannot hold 0.1 exactly, and why sums such as 0.1 + 0.2 can come out a hair off in a spreadsheet or program.

Binary addition with carry, subtraction, multiplication and division

Binary arithmetic follows the same column methods you learned for decimal, with smaller tables. The only new fact for addition is that 1 + 1 makes 2, which is written 10 in binary: put down 0 and carry 1.

Addition with carry, 1011 + 111 (11 + 7): the right column 1 + 1 = 10, write 0 carry 1; next 1 + 1 + 1 = 11, write 1 carry 1; next 0 + 1 + 1 = 10, write 0 carry 1; next 1 + 1 = 10, write 0 carry 1; the last carry goes in front. The answer, 10010, is 16 + 2 = 18, the same as the calculator's Sum in binary.

Subtraction with borrowing, 11010 − 1011 (26 − 11): whenever the top digit is smaller, borrow from the next place, which turns the 0 into 10 (two). Here the first four columns from the right all need a borrow, and the answer is 1111, which is 15.

Multiplication is shift and add. For 1011 × 101 (11 × 5), the 1 on the right gives 1011, the 0 gives a row of zeros, and the 1 on the left gives 1011 moved two places, 101100. Adding 1011 + 101100 gives 110111, which is 55.

Division is long division where each step either fits once or not at all. For 11011 ÷ 101 (27 ÷ 5): 101 fits into 110 once, leaving 1; bring down 1 to make 11, which is too small, so write 0; bring down the last 1 to make 111, which fits once and leaves 10. The calculator shows Quotient 101 and Remainder 10, that is 5 remainder 2, and the Exact quotient 101.0110011…, which is 5.4.

Signed binary and two's complement

Written on paper, a negative binary number just takes a minus sign, so 5 − 10 = −101. A computer has no minus sign to store; it keeps whole numbers in a fixed number of bits and uses two's complement for the negative ones, which is the representation Intel's x86 processors use for signed integers. To get it by hand, write the positive number in the full width, flip every bit and add 1: 5 is 00000101, flipped 11111010, plus 1 gives 11111011, which is −5 in 8 bits. The calculator does this for you, and the formula behind it is 2ʷ + n: for −100 in 8 bits, 256 − 100 = 156 = 10011100.

The first bit then acts as the sign: 0 for zero and positive numbers, 1 for negative ones. With w bits you can store 2ʷ different patterns, split between negatives and non-negatives, which gives these ranges:

The Cambridge O Level Computer Science syllabus (2210, exams in 2026 to 2028) lists exactly these skills: converting between denary (its word for decimal), binary and hexadecimal up to 16 bits, adding 8-bit binary numbers, explaining overflow above 255, logical shifts, and 8-bit two's complement. This calculator is a handy way to check that kind of past-paper answer.

AND, OR, XOR and logic gates

The three bitwise operations compare the two numbers one column at a time, exactly like the logic gates in a digital circuit. Each output bit depends only on the two input bits above it:

With 11001010 and 11110000 (202 and 240), the calculator gives AND 11000000 (192), OR 11111010 (250) and XOR 111010 (58; the Bit by bit table shows it as 00111010 so the columns line up). AND keeps only the bits that are on in both, so it is used as a mask to pick out part of a number; OR switches bits on; XOR flips them, and doing the same XOR twice gets the original back.

Networking is a familiar use. An IPv4 address is 32 bits, written as four 8-bit numbers: 192.168.1.1 is 11000000.10101000.00000001.00000001. ANDing the address with the subnet mask 255.255.255.0 clears the last eight bits and leaves the network address, 192.168.1.0. The IP Subnet Calculator does that whole job for you.

Common mistakes and related calculators

  • Reading the remainders top to bottom: in decimal to binary, the last remainder is the leftmost digit.
  • Forgetting the carry when 1 + 1 + 1 appears in a column: write 1 and carry 1.
  • Typing a 2 or another digit: only 0 and 1 are binary digits, and the calculator names the first wrong one.
  • Comparing two's complement with the minus-sign form: 11111011 and −101 are the same −5, written two ways.
  • Expecting a fraction in Calculate mode: there the numbers must be whole; use Binary to decimal for 101.01.

For base 16 work, use the Hex Calculator. The Big Number Calculator handles very long decimal numbers such as 2^100, and the Scientific Calculator covers everyday maths.

How it works

Binary numbers use only the digits 0 and 1, and each place is worth twice the place to its right (1, 2, 4, 8, 16 …). Pick Calculate to add, subtract, multiply or divide two binary numbers (division gives a whole-number quotient and a remainder) or to combine them bit by bit with AND, OR and XOR. The answer is shown in binary, in decimal, in hexadecimal and in octal. The two converters change binary to decimal by adding up the place values, and decimal to binary by dividing by 2 again and again; a decimal fraction such as 10.5 becomes 1010.1.

The formula

  • Binary to decimal: d = bₙ×2ⁿ + … + b₂×2² + b₁×2¹ + b₀×2⁰ (+ b₋₁×2⁻¹ + … after the point)
  • Decimal to binary: divide by 2 and keep the remainders; read them from the last to the first
  • Fractions: multiply the part after the point by 2; each whole part (0 or 1) is the next digit
  • Division: a = q × b + r with 0 ≤ |r| < |b| (q rounded toward zero)
  • Two's complement of a negative n in w bits: 2ʷ + n

A worked example

10101010 + 11001100: in decimal 170 + 204 = 374, and 374 = 256 + 64 + 32 + 16 + 4 + 2, which is 101110110 in binary. To turn 170 into binary: 170 ÷ 2 = 85 r 0, 85 ÷ 2 = 42 r 1, 42 ÷ 2 = 21 r 0, 21 ÷ 2 = 10 r 1, 10 ÷ 2 = 5 r 0, 5 ÷ 2 = 2 r 1, 2 ÷ 2 = 1 r 0, 1 ÷ 2 = 0 r 1; reading up gives 10101010.

Questions

How do I calculate binary numbers step by step?

Line the numbers up on the right and work column by column, as in decimal, using the rules 1 + 1 = 10 and 0 − 1 = 1 with a borrow. Type both numbers into the Calculate tab and the page gives the answer in binary with the same sum worked in decimal, so you can check each stage.

What is the formula to convert binary to decimal?

Multiply each digit by its power of 2 and add: d = bₙ×2ⁿ + … + b₁×2 + b₀. For 1011 that is 1×8 + 0×4 + 1×2 + 1×1 = 11. Only the places holding a 1 count, so in practice you just add their place values.

How do you convert decimal to binary?

Divide by 2 and write down the remainder, then keep dividing the quotient until it is 0. Read the remainders from the last to the first: 13 gives remainders 1, 0, 1, 1, so 13 = 1101. The Decimal to binary tab prints this table for any number.

How does binary addition with carry work?

Whenever a column adds up to 2 (1 + 1), write 0 and carry 1 to the next column; when it adds up to 3 (1 + 1 + a carry), write 1 and carry 1. A carry out of the leftmost column becomes a new leading 1, which is why 1111 + 1 = 10000.

How do I find the 2's complement of a binary number?

Write the number in the full width (8 bits, say), flip every 0 to 1 and every 1 to 0, then add 1. For 6 that is 00000110, flipped 11111001, plus 1 gives 11111010, which stands for −6. The calculator shows the two's complement automatically for any negative answer.

Can the binary calculator work with a decimal point?

Yes, in the two converters. Binary to decimal reads digits after the point (101.01 = 5.25), and Decimal to binary turns 10.5 into 1010.1 and tells you when the digits repeat forever, as they do for 0.1. The Calculate tab works with whole numbers.

How do I convert binary to hexadecimal?

Split the binary digits into groups of four from the right, adding zeros at the front if needed, and replace each group with one hex digit (0000 = 0 up to 1111 = F). 10110111 becomes 1011 0111, which is B7. Every result on this page also lists the hexadecimal form.

How do I calculate binary on a Casio scientific calculator?

Models such as the Casio fx-991ES PLUS have a BASE-N mode with a BIN key for binary, plus keys for decimal, hex and octal. Casio's guide says that mode handles whole numbers only (fractions are cut off) and shows negative binary numbers in two's complement within a 16-bit range, so longer numbers and fractions need a tool like this one.

How do I convert an IP address to binary?

Convert each of the four numbers separately into 8 bits, padding with zeros at the front. 192.168.1.1 becomes 11000000.10101000.00000001.00000001. Use the Decimal to binary tab for each part, or the IP Subnet Calculator for masks and network ranges.

Can binary be turned into words or text?

Text is stored as numbers: in ASCII each character has a code, and 8 bits hold one character. 01001000 is 72, the code for H, and 01101001 is 105, the code for i, so that pair spells Hi. This calculator converts the numbers; look the codes up in an ASCII table to read the letters.

What is the binary number system and why do computers use it?

It is a base 2 place-value system: every number is written with 0s and 1s, and each place is worth double the one to its right. Electronic circuits only need to tell two states apart, on and off, which makes binary reliable and cheap to build, so all data in a computer is stored and processed as bits.
