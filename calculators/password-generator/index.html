How it works

Choose how long the password should be and which kinds of character it may use. Every character is picked by your browser's secure random number generator (Web Crypto), with every allowed character equally likely, and each kind you tick appears at least once. Look-alike characters such as l, 1 and I or O and 0 are left out by default, and so are brackets, which some websites refuse. The strength is measured in bits of entropy: each bit doubles the number of guesses an attacker would need. Nothing is sent to a server or saved, so copy the password into a password manager before you leave the page.

The formula

  • Pool size N = the number of different characters allowed
  • Entropy (repeats allowed) = length × log₂ N bits
  • Entropy (each character once) = log₂ (N × (N − 1) × … × (N − length + 1)) bits
  • Possible passwords = 2 to the power of the entropy
  • Strength: under 36 bits very weak, 36-47.9 weak, 48-59.9 good, 60-119.9 strong, 120 or more very strong

A worked example

16 characters from lowercase letters, capitals, numbers and symbols, with look-alikes and brackets left out: N = 23 + 23 + 9 + 13 = 68 characters, so the entropy is 16 × log₂ 68 = 16 × 6.09 = 97.4 bits (strong). Allowing every character (N = 93) gives 104.6 bits.

Questions

Is it safe to make a password on a website?

Here, yes: the password is made inside your own browser with its secure random number generator. It is not sent to any server, not put in the page address and not stored, so nobody else ever sees it. Copy it into a password manager, then close the page.

How long should my password be?

For an account protected only by its password, use 15 characters or more; 16 random characters with all four kinds give about 97 bits, far beyond guessing. Where a site limits the length or the symbols, use the longest password it accepts and untick the kinds it refuses.

What does entropy in bits mean?

It counts how many guesses an attacker would need in the worst case: n bits means 2 to the power n possible passwords. Every extra bit doubles the work, so 60 bits is a million times harder to guess than 40 bits. Length adds entropy faster than extra kinds of character.

Why leave out look-alike characters and brackets?

Characters like l, I and 1 or O and 0 are easy to misread when you type a password from paper or another screen, and some websites reject brackets or quote marks. Leaving them out makes the pool a little smaller, which you can make up for with one or two more characters.

What does "Use each character only once" do?

No character appears twice in the password. Some older systems ask for this. It makes the password slightly weaker for the same length, because there are fewer possible passwords, and the length can be at most the number of allowed characters.
