What future value means

A future value calculator tells you what money will be worth at a later date once it has earned interest. Future value (FV) is the balance you end up with when a lump sum, a series of equal deposits, or both, grow at a steady rate for a set number of periods.

It rests on the time value of money: a sum today is worth more than the same sum later, because today's money can earn interest in the meantime. Future value looks forward from today; present value looks back from the future. Together with the rate, the number of periods and the payment, they are the five numbers used in almost every savings, loan and investment calculation.

How to use the future value calculator

  • Choose the currency; it changes only the symbol.
  • Starting amount: the lump sum you have today (10,000 by default). Enter 0 if you are starting from nothing.
  • Deposit each period: the same amount added every period (200 by default). Enter 0 for a lump sum on its own.
  • Number of periods: years, months or any equal step. Use 120 for 10 years of monthly deposits.
  • Interest rate per period: the rate for one of those same periods. For 6% a year with monthly deposits, enter 0.5.
  • Deposit timing: End of each period (the usual case, an ordinary annuity) or Start of each period (an annuity due).

The future value formula

For a lump sum: FV = PV × (1 + i)^N, where PV is the amount today, i the rate per period as a decimal and N the number of periods. The term (1 + i)^N is the future value interest factor; at 6% for 10 periods it is 1.7908, so 10,000 becomes 17,908.48.

For equal deposits at the end of each period (the future value of an annuity): FV = PMT × ((1 + i)^N − 1) ÷ i. If the deposits are made at the start of each period, multiply by (1 + i), because each deposit earns one extra period of interest.

For both together, add the two parts. With the defaults: 10,000 × 1.06^10 = 17,908.48 and 200 × (1.06^10 − 1) ÷ 0.06 = 2,636.16, for a future value of 20,544.64. With simple interest, where interest is never added to the balance, the lump-sum formula is just PV × (1 + i × N).

How to calculate future value in Excel or on a financial calculator

Excel's FV function is =FV(rate, nper, pmt, [pv], [type]). Money you pay in is entered as a negative number, so the defaults are =FV(6%, 10, -200, -10000), which returns 20,544.64. Set type to 1 for deposits at the start of each period; that returns 20,702.81. For monthly contributions, divide a yearly rate by 12 and multiply the years by 12: =FV(6%/12, 120, -200, -10000).

On a financial calculator such as the BA II Plus, enter N = 10, I/Y = 6, PV = −10,000 and PMT = −200, then compute FV. The keys match the boxes on this page: N is the number of periods, I/Y the rate per period, PV the starting amount and PMT the deposit.

Worked examples

Monthly contributions. Start with $10,000 and add $200 a month for 10 years at 6% a year: enter 120 periods at 0.5% a period. The future value is $50,969.84, of which $24,000 is deposits and $16,969.84 is interest.

Deposits at the start. With the default yearly plan but deposits on the first day of each year, the future value rises from 20,544.64 to 20,702.81, because each 200 earns interest for one more year.

Saving in Pakistan. You put Rs 100,000 into a fund today and add Rs 10,000 every month for 5 years. If it earns 1% a month, enter 60 periods at 1%: the future value is Rs 998,366.37, of which Rs 700,000 is your own money and Rs 298,366.37 is profit. A plan like this is often called a SIP (systematic investment plan); fund returns are not fixed, so try a lower rate as well.

Future value with inflation

A future value is in future money. To see what it will buy in today's prices, use the real rate of return instead of the nominal one: real rate = (1 + rate) ÷ (1 + inflation) − 1. With a 6% return and 3% inflation, the real rate is 1.06 ÷ 1.03 − 1 = 2.913%.

Enter 2.913% instead of 6% and the default 10,000 lump sum grows to 13,326.08 in today's money after 10 years, against 17,908.48 in future money. Both are correct; they simply measure in different units. For long plans, always look at the real figure before deciding whether a savings target is enough.

Tips and related tools

  • Keep the rate and the periods in the same unit: a monthly plan needs a monthly rate.
  • A small difference in the rate matters more the longer the plan runs, so test a cautious rate too.
  • Fees and taxes reduce the effective rate; subtract them before you enter it.
  • For deposits that change, withdrawals, or a plan that stops halfway, use a schedule tool rather than a single formula.

How it works

Enter what you start with, what you add each period, how many periods and the interest rate for one period. Each period the balance earns interest at that rate; a deposit made at the start of a period earns interest in that period too, one made at the end starts earning in the next. The future value is the balance after the last period. The present value shows what the whole plan is worth today: the starting amount plus every deposit brought back to today at the same rate.

The formula

  • FV = start × (1 + i)^N + PMT × ((1 + i)^N − 1) ÷ i, with i = the rate per period ÷ 100
  • Deposits at the start of each period: the deposit part × (1 + i)
  • At 0%: FV = start + PMT × N
  • Present value = start + PMT × (1 − (1 + i)^−N) ÷ i (× (1 + i) for deposits at the start)
  • Total interest = FV − start − PMT × N

A worked example

Start with $1,000 and add $100 at the end of each of 10 years at 6%. The $1,000 grows to 1,000 × 1.06^10 = $1,790.85 and the deposits to 100 × (1.06^10 − 1) ÷ 0.06 = $1,318.08, so the future value is $3,108.93. You put in $2,000, so $1,108.93 is interest.

Questions

How do I calculate future value?

For a lump sum, multiply it by (1 + rate per period) raised to the number of periods. For equal deposits, add PMT × ((1 + i)^N − 1) ÷ i. This calculator does both at once and shows the schedule.

What is the future value formula with monthly contributions?

Use the monthly rate i = yearly rate ÷ 12 and N = years × 12, then FV = start × (1 + i)^N + PMT × ((1 + i)^N − 1) ÷ i. $10,000 plus $200 a month at 6% for 10 years gives $50,969.84.

What is a period?

Any fixed step of time: a year, a month, a week. Use the interest rate for that same step. For 5% a year with monthly deposits, use about 0.417% a period and 12 periods for each year.

Does it matter if I deposit at the start or the end of each period?

Yes. A deposit at the start earns interest for the whole period it is made in, so the future value is higher. Most savings plans that take money on payday are close to end of period.

How do I calculate future value in Excel?

Use =FV(rate, nper, pmt, pv, type) with money paid in as negative numbers, for example =FV(6%, 10, -200, -10000) for the defaults, which gives 20,544.64. Use type 1 for deposits at the start of each period.

What does the present value tell me?

It is the single amount that, put away today at the same rate, would grow to the same future value. It helps compare a savings plan with a lump sum.

How do I include inflation in future value?

Enter the real rate, (1 + return) ÷ (1 + inflation) − 1, instead of the nominal return. The result is then in today's money: at 6% return and 3% inflation, use about 2.913%.

Can the rate be negative?

Yes, down to just above -100%. A negative rate shows money losing value, for example after fees or inflation, and the interest line then shows a loss.
