What percent error means

Percent error tells you how far a measured or experimental value is from the true, accepted or theoretical value, as a percentage of that true value. A percent error calculator saves the arithmetic and shows the steps, which is handy for chemistry and physics lab reports.

A small percent error means your result is close to the accepted value; a large one points to a mistake, a faulty instrument or a method that needs another look. A result of 0% means the measurement matched exactly.

How to use the percent error calculator

  • Measured value: what you got in the experiment, estimate or reading (the page starts with 48).
  • True value: the accepted, expected, theoretical or exact value you compare against (the page starts with 50). It cannot be 0.
  • Read the Percent error, without a sign, and the Signed percent error beside it, which says whether you were too low (−) or too high (+).
  • Below them you get the signed error at full precision, the Difference (measured − true) and the Relative error as a decimal.
  • Open the steps to copy the working: the formula, your numbers in it, and the division.

With the defaults, (48 − 50) ÷ 50 × 100% = −4%: the measurement is 4% below the true value, so the percent error is 4%.

The percent error formula, with worked examples

Percent error = |measured − true| ÷ |true| × 100%. In words: find the difference, ignore its sign, divide by the true value and multiply by 100. Dividing by the measured value instead is the most common slip; the true value always goes on the bottom.

Percent error, percent difference, percent change and percent yield

These four look alike but answer different questions, and mixing them up costs marks in reports.

Percent yield and percent error are related: a yield of 95.56% is the same as being 4.44% short of the theoretical amount. For a change or a percent of a number, use the Percentage Calculator.

Percent error with multiple trials

When you repeat an experiment, the usual way is to average the trials first and then find the percent error of the mean. Three pendulum trials of 9.72, 9.85 and 9.78 m/s² average 9.7833 m/s², which is 0.2718% below 9.81.

Working out the percent error of each trial (0.9174%, 0.4077% and 0.3058%) and averaging those gives 0.5437% instead, because the low and high trials no longer cancel out. Say in your report which method you used. To describe how much the trials scatter, add their standard deviation from the Standard Deviation Calculator.

Percent error in Excel or Google Sheets

Put the measured value in A2 and the true value in B2, then type =ABS(A2-B2)/ABS(B2) and format the cell as a percentage. For the signed error, leave out the first ABS: =(A2-B2)/ABS(B2). If you prefer a plain number, multiply by 100 instead of using the percent format. Fill the formula down to handle a whole table of trials at once.

What percent error is acceptable?

There is no single cut-off; it depends on the equipment and the task. A useful test is to compare the percent error with the uncertainty of your instrument. A ruler with 1 mm marks read to ±0.5 mm on a 50 mm rod has an uncertainty of about 1%, so a 1% error is as good as that ruler allows, while a 10% error means something else went wrong.

Errors fall into two kinds. Random errors scatter results both ways and shrink when you average more trials. Systematic errors push every result the same way, such as a balance that reads 0.2 g heavy, and averaging does not remove them. A signed error that keeps the same sign across trials is a hint of a systematic error.

Common mistakes

  • Dividing by the measured value: the true value goes on the bottom.
  • Forgetting to multiply by 100, which leaves the relative error (0.044 instead of 4.4%).
  • Using Celsius or Fahrenheit near zero. A true value of 0 °C has no percent error at all, and small temperatures give huge percents. Use kelvin (0 °C = 273.15 K, so a reading of 0.5 °C is 0.183% off) or report the plain difference.
  • Mixing units, such as a measured value in grams and a true value in kilograms.
  • Quoting too many digits: round the percent error so it claims no more precision than your measurements.

How it works

Type what you measured and the true (accepted) value. The percent error is the gap between them as a share of the true value: subtract, divide by the true value, then multiply by 100. The big number has no sign, which is how most lab reports quote it. The signed error beside it keeps the sign: a minus means your measurement came out too low, a plus means too high. The steps keep 14 significant digits; the headline is rounded to 4 decimal places.

The formula

  • Percent error = |measured − true| ÷ |true| × 100%
  • Signed percent error = (measured − true) ÷ |true| × 100% (minus: too low, plus: too high)
  • Relative error = (measured − true) ÷ |true| (the same without × 100)
  • The true value cannot be 0

A worked example

A pendulum experiment gives g = 9.6 m/s², and the accepted value is 9.81 m/s². The difference is 9.6 − 9.81 = −0.21, and −0.21 ÷ 9.81 = −0.021407 (about), so the signed error is −2.1407% and the percent error is 2.1407%: the measurement was about 2.14% too low.

Questions

How do I calculate percent error?

Subtract the true value from the measured value, drop the minus sign, divide by the true value and multiply by 100. Measured 48 against a true 50 gives 2 ÷ 50 × 100 = 4%.

How do I calculate percent error in chemistry?

Use the experimental result as the measured value and the accepted or theoretical value from your book or data table as the true value. A density of 2.58 g/cm³ for aluminium, accepted 2.70 g/cm³, is 4.44% off.

Can percent error be negative?

The usual percent error has no sign, because it only measures the size of the gap. The signed version keeps the sign to show the direction: −5% means the measurement was 5% below the true value, +5% means 5% above.

What is the difference between percent error and percent difference?

Percent error compares a result with a value known to be correct and divides by that true value. Percent difference compares two results when neither is known to be right, and divides by their average.

How do I calculate percent error with multiple trials?

Average the trials, then find the percent error of the average against the true value. Averaging the separate percent errors gives a different, usually larger, number, so say which method you used.

How do I calculate percent error in Excel?

With the measured value in A2 and the true value in B2, type =ABS(A2-B2)/ABS(B2) and format the cell as a percentage. Remove the first ABS to keep the sign.

What is a good percent error?

It depends on the equipment. Compare it with the uncertainty of your instrument: if the error is about the size of that uncertainty, the result is as good as the tool allows; if it is much bigger, look for a mistake or a systematic error.

Is percent error the same as percent yield?

No. Percent yield is actual ÷ theoretical × 100 and says how much product you made. Percent error says how far you were from the expected value; a 95% yield is a 5% error.

Why can the true value not be 0?

Percent error divides by the true value, and dividing by 0 has no answer. To compare with a true value of 0, report the plain difference (measured − true) instead.

What if the true value is negative?

The bottom of the fraction uses the size of the true value, so the sign still means above or below. A measured −4 against a true −5 is 1 above, which is +20% (the plain percent error is 20% either way).
