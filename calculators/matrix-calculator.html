What a matrix is and what this matrix calculator does

A matrix is a rectangular grid of numbers arranged in rows and columns. Its size is written rows × columns, so [[1, 2, 3], [4, 5, 6]] is a 2 × 3 matrix: two rows, three columns. Each number is an entry, and the entry in row i and column j is written aᵢⱼ. A square matrix has as many rows as columns, and the identity matrix I is the square matrix with 1s down the main diagonal and 0s everywhere else; it plays the part of the number 1 in multiplication.

Other special kinds have names too: a row matrix (1 × n) and a column matrix (n × 1, also called a vector), the zero matrix (all 0s), a diagonal matrix (non-zero entries only on the main diagonal), an upper or lower triangular matrix (only 0s below or above the diagonal) and a symmetric matrix (equal to its transpose). Textbook questions often start by asking you to name the type and the order (size) of a matrix.

This matrix calculator takes two matrices, A and B, each up to 10 × 10, and works out the determinant, inverse, transpose, a power, a multiple by a number, or the reduced row echelon form and rank of either one, as well as A + B, A − B and A × B. Every answer is exact: the arithmetic is done with fractions, never rounded, so a 10 × 10 determinant of whole numbers comes out as a whole number. You can see the answers as fractions or as decimals, with the key steps.

Matrices store and transform data in one block. They describe systems of linear equations, rotate and scale images in computer graphics, link currents in electrical circuits, hold the weights of statistical and machine-learning models, and model how populations or markets move from one state to the next. Learning the handful of operations below covers most of what school and university courses ask.

How to use the matrix calculator

  • Pick an operation under What to work out: Determinant, Inverse (chosen to start), Transpose, Power (matrix to a power), Multiply by a number, Row echelon form (RREF) and rank, A + B, A − B or A × B.
  • For the first six, choose under Of matrix whether to use A or B.
  • Set each matrix's size with the − and + buttons (1 to 10 rows and columns) and type the entries: whole numbers, decimals like −2.5 or fractions like 3/4. Empty boxes count as 0, and a block copied from a spreadsheet can be pasted straight in.
  • The page opens with A = [[2, −1, 0], [−1, 2, −1], [0, −1, 2]] and B = [[1, 2, 0], [0, 1, 3], [4, 0, 1]], two 3 × 3 matrices that give tidy answers.
  • For a power, type the Power (from −20 to 50; 0 gives the identity matrix and a negative power uses the inverse). For Multiply by a number, type the Number to multiply by, such as 3, −0.5 or 2/3.
  • Under Show answers as, choose Fractions or Decimals (10 significant digits).
  • Use Swap to exchange A and B (for B × A, say), and Put the answer in A or B to carry the result into the next calculation, for example to find A³ × B or to check that A × A⁻¹ = I.

Understanding the results

  • The answer matrix is drawn in brackets, with its Size (rows × columns) underneath. Answer as a table, below the results, holds the same numbers row by row and can be downloaded as CSV for a spreadsheet.
  • Determinant also gives the Trace (the sum of the main diagonal) and Has an inverse: Yes, or No when the determinant is 0.
  • Inverse also shows the determinant of the matrix you inverted, and the steps give the 2 × 2 shortcut or the [A | I] method for larger matrices.
  • Row echelon form shows the reduced row echelon form (RREF), the Rank and the pivot columns.
  • A × B shows how the first box was found (row 1 times column 1), so you can check the method by hand.
  • When an answer has very long fractions, a note suggests switching to Decimals. If a box was left empty, a note says how many counted as 0.
  • An operation that cannot be done gets a plain message instead of an answer: a determinant or inverse of a non-square matrix, an inverse when the determinant is 0, A + B with different sizes, or A × B when the columns of A do not match the rows of B.

Adding, subtracting and multiplying a matrix by a number

Matrices of the same size are added or subtracted box by box: the entry in row i, column j of A + B is aᵢⱼ + bᵢⱼ. Matrices of different sizes cannot be added at all. With the opening matrices:

A + B = [[2 + 1, −1 + 2, 0 + 0], [−1 + 0, 2 + 1, −1 + 3], [0 + 4, −1 + 0, 2 + 1]] = [[3, 1, 0], [−1, 3, 2], [4, −1, 3]], and A − B = [[1, −3, 0], [−1, 1, −4], [−4, −1, 1]].

Multiplying by a number (a scalar) multiplies every entry: ½ × [[4, −2], [6, 3]] = [[2, −1], [3, 3/2]]. Addition is commutative (A + B = B + A) and the zero matrix, all 0s, changes nothing when added. Brackets can be moved freely, (A + B) + C = A + (B + C), and a number spreads over a sum, k(A + B) = kA + kB.

Matrix multiplication with steps

Matrix multiplication is not box by box. Each entry of A × B is a row of A combined with a column of B: multiply the matching entries and add them up. So A × B needs as many columns in A as there are rows in B, and the answer has the rows of A and the columns of B.

Worked example: A = [[1, 2], [3, 4]] and B = [[5, 6], [7, 8]]. Row 1 × column 1 = 1×5 + 2×7 = 19; row 1 × column 2 = 1×6 + 2×8 = 22; row 2 × column 1 = 3×5 + 4×7 = 43; row 2 × column 2 = 3×6 + 4×8 = 50. So A × B = [[19, 22], [43, 50]].

Order matters. Swapping gives B × A = [[23, 34], [31, 46]], a different matrix. With the opening 3 × 3 matrices, A × B = [[2, 3, −3], [−5, 0, 5], [8, −1, −1]] but B × A = [[0, 3, −2], [−1, −1, 5], [8, −5, 2]]. That is why the calculator has a Swap button.

Different sizes: [[1, 2, 3], [4, 5, 6]] (2 × 3) times [[7, 8], [9, 10], [11, 12]] (3 × 2) gives the 2 × 2 matrix [[58, 64], [139, 154]], since 1×7 + 2×9 + 3×11 = 58.

A matrix times a column transforms a point. The rotation matrix [[0, −1], [1, 0]] turns the point (3, 1), written as the column [3; 1], into [−1; 3], a quarter turn anticlockwise about the origin. Chains of such products are how graphics software moves, turns and scales shapes.

How to calculate the determinant of a matrix

The determinant is a single number worked out from a square matrix. For a 2 × 2 matrix [[a, b], [c, d]] it is ad − bc: for [[1, 2], [3, 4]], 1×4 − 2×3 = −2, and for [[3, 8], [4, 6]], 18 − 32 = −14.

For a 3 × 3 matrix, expand along the first row. With rows (a, b, c), (d, e, f) and (g, h, i), det = a×(e×i − f×h) − b×(d×i − f×g) + c×(d×h − e×g), where the signs alternate +, −, +. The calculator's steps for the opening A = [[2, −1, 0], [−1, 2, −1], [0, −1, 2]] read: the three 2 × 2 determinants are 3, −2 and 1, so det(A) = 2×3 − (−1)×(−2) + 0×1 = 6 − 2 + 0 = 4. For B the determinant is 25.

For 4 × 4 and larger, cofactor expansion gets slow (a 10 × 10 matrix would need millions of products), so the calculator row-reduces the matrix to a triangle and multiplies the diagonal, flipping the sign for each row swap. For a triangular matrix that is immediate: [[2, 0, 0, 0], [1, 3, 0, 0], [4, 5, −1, 0], [7, 8, 9, 2]] has determinant 2 × 3 × (−1) × 2 = −12.

Geometrically, the determinant of a 2 × 2 matrix is the factor by which it scales areas, and of a 3 × 3 matrix the factor for volumes; a negative sign means the shape is also flipped over. [[2, 0], [0, 3]] stretches by 2 one way and 3 the other, so areas grow 6 times, and its determinant is 6. A determinant of 0 means the matrix squashes the plane or space flat, which is why such a matrix has no inverse.

How to find the inverse of a matrix

The inverse A⁻¹ undoes A: A × A⁻¹ = A⁻¹ × A = I. Only a square matrix with a determinant other than 0 has one; a matrix with determinant 0 is called singular. For a 2 × 2 matrix there is a shortcut: swap a and d, change the signs of b and c, and divide by the determinant. For [[1, 2], [3, 4]] with determinant −2, that gives 1/(−2) × [[4, −2], [−3, 1]] = [[−2, 1], [3/2, −1/2]], or [[−2, 1], [1.5, −0.5]] in decimals. For [[4, 7], [2, 6]] (determinant 10) the inverse is [[3/5, −7/10], [−1/5, 2/5]].

For 3 × 3 and larger, the calculator uses Gauss-Jordan elimination: write A beside the identity, [A | I], and use row operations until the left half becomes I; the right half is then A⁻¹. The opening matrix gives A⁻¹ = [[3/4, 1/2, 1/4], [1/2, 1, 1/2], [1/4, 1/2, 3/4]], and det(A) = 4 explains the quarters. The other classroom method, the adjugate (the transpose of the matrix of cofactors) divided by the determinant, gives the same answer with more arithmetic.

To check any inverse, put it in B with the original in A and choose A × B: the answer must be the identity matrix. For a product, the order reverses: (AB)⁻¹ = B⁻¹A⁻¹.

Transpose, matrix powers, RREF, rank and systems of equations

The transpose Aᵀ turns rows into columns, so an m × n matrix becomes n × m: [[1, 2, 3], [4, 5, 6]]ᵀ = [[1, 4], [2, 5], [3, 6]]. A matrix equal to its own transpose, like the opening A, is called symmetric. A useful rule: (AB)ᵀ = BᵀAᵀ.

A power multiplies a square matrix by itself: A² = A × A, so [[1, 2], [3, 4]]² = [[7, 10], [15, 22]], not the squares of the entries. A⁰ is the identity and A⁻¹ is the inverse. A neat example is the Fibonacci matrix [[1, 1], [1, 0]]: its 10th power is [[89, 55], [55, 34]], three consecutive Fibonacci numbers.

Row operations (swapping rows, multiplying a row by a non-zero number, adding a multiple of one row to another) do not change the solutions of the equations a matrix stands for. Using them to get a leading 1 in each row, with 0s above and below it, gives the reduced row echelon form. The rank is the number of non-zero rows left: [[1, 2, 3], [4, 5, 6], [7, 8, 9]] reduces to [[1, 0, −1], [0, 1, 2], [0, 0, 0]], so its rank is 2 and its determinant is 0.

To solve simultaneous equations, put the coefficients and the right-hand sides in one augmented matrix and take its RREF. For 2x + y = 5 and x − y = 1, the matrix [[2, 1, 5], [1, −1, 1]] reduces to [[1, 0, 2], [0, 1, 1]], so x = 2 and y = 1. For x + y + z = 6, 2y + 5z = −4 and 2x + 5y − z = 27, the 3 × 4 matrix [[1, 1, 1, 6], [0, 2, 5, −4], [2, 5, −1, 27]] reduces to x = 5, y = 3, z = −2.

The matrix inversion method gives the same answer as x = A⁻¹b: for the first system, A⁻¹ = [[1/3, 1/3], [1/3, −2/3]], and A⁻¹ × [5; 1] = [2; 1]. If the coefficient matrix has determinant 0, the system has either no solution or infinitely many, and the RREF shows which: a row like [0, 0, 1] means no solution.

For a 2 × 2 system, Cramer's rule is a third route: x = det(Aₓ) ÷ det(A) and y = det(Aᵧ) ÷ det(A), where Aₓ and Aᵧ replace the x or y column with the right-hand sides. For 2x + y = 5 and x − y = 1, det(A) = −3, det([[5, 1], [1, −1]]) = −6 and det([[2, 5], [1, 1]]) = −3, so x = 2 and y = 1 again.

Matrices at school, on a Casio, in Excel, and common mistakes

For A Level students in Pakistan and elsewhere, Cambridge AS and A Level Further Mathematics (9231, exams in 2026 and 2027) covers matrix addition and multiplication, determinants and inverses of 2 × 2 and 3 × 3 matrices, (AB)⁻¹ = B⁻¹A⁻¹, 2 × 2 matrices as rotations, reflections, enlargements, stretches and shears (with the determinant as the area scale factor), solving three equations in three unknowns, and eigenvalues and eigenvectors. This calculator does everything on that list except eigenvalues.

On a scientific calculator, the Casio fx-991ES PLUS has a MATRIX mode for matrices up to 3 × 3, stored as MatA, MatB and MatC, with det, Trn (transpose) and the inverse; the newer fx-991CW's Matrix app goes up to 4 × 4 with MatA to MatD. In Excel, =MMULT multiplies two ranges, =MINVERSE inverts a square range, =MDETERM gives the determinant and =TRANSPOSE flips a range. This page has no such size limits up to 10 × 10 and gives exact fractions instead of rounded decimals.

  • Multiplying box by box: that is not matrix multiplication (and A² is not the squares of the entries).
  • Assuming A × B = B × A: usually they differ.
  • Forgetting the alternating signs (+, −, +) in a 3 × 3 determinant.
  • Trying to invert a matrix with determinant 0, or a matrix that is not square.
  • Dividing matrices: there is no such operation; multiply by an inverse instead, on the correct side.

Related: the Fraction Calculator for checking fraction arithmetic in an inverse, the Quadratic Formula Calculator for the characteristic equation of a 2 × 2 matrix, and the Scientific Calculator for everything else.

How it works

Set the size of each matrix with the − and + buttons (up to 10 rows and 10 columns), type the numbers into the boxes, and pick what to work out. Boxes take whole numbers, decimals and fractions such as 3/4; an empty box counts as 0, and you can paste a block of numbers copied from a spreadsheet. Every answer is worked out exactly with fractions, so the inverse of a matrix of whole numbers comes out as clean fractions; switch to Decimals if you prefer. Use "Put the answer in A" (or B) to carry on with the result, and Swap to exchange A and B.

The formula

  • A + B and A − B: add or subtract the boxes in the same place (same sizes only)
  • A × B: box (i, j) = row i of A times column j of B, added up; needs columns of A = rows of B
  • k × A: every box times k; Aᵀ: rows become columns
  • det [[a, b], [c, d]] = ad − bc; larger: row-reduce to a triangle and multiply the diagonal
  • A⁻¹: row-reduce [A | I] to [I | A⁻¹]; it exists only when det(A) ≠ 0
  • Aⁿ = A × A × … × A (n times); A⁰ = I; A⁻ⁿ = (A⁻¹)ⁿ

A worked example

For A = [[1, 2], [3, 4]], det(A) = 1×4 − 2×3 = −2, so the inverse is 1/(−2) × [[4, −2], [−3, 1]] = [[−2, 1], [3/2, −1/2]]. With B = [[5, 6], [7, 8]], the top-left box of A × B is 1×5 + 2×7 = 19.

Questions

How do I calculate a matrix multiplication?

Take each row of the first matrix and each column of the second, multiply the matching entries and add them; that sum goes in the answer at that row and column. For [[1, 2], [3, 4]] × [[5, 6], [7, 8]] the top-left entry is 1×5 + 2×7 = 19, and the full answer is [[19, 22], [43, 50]].

When can I multiply two matrices?

A × B works when A has as many columns as B has rows; a 2 × 3 matrix times a 3 × 4 matrix gives a 2 × 4 matrix. Order matters: A × B is usually not the same as B × A, so use Swap to get B × A.

How do I calculate the determinant of a 3 × 3 matrix?

Expand along the first row: det = a×(e×i − f×h) − b×(d×i − f×g) + c×(d×h − e×g) for rows (a, b, c), (d, e, f), (g, h, i). Each bracket is the determinant of the 2 × 2 block left when you cross out that entry's row and column. For [[2, −1, 0], [−1, 2, −1], [0, −1, 2]] the result is 2×3 − (−1)×(−2) + 0 = 4.

How do I find the inverse of a 2 × 2 matrix?

For [[a, b], [c, d]], swap a and d, change the signs of b and c, and divide every entry by ad − bc. If ad − bc is 0 the matrix has no inverse. [[1, 2], [3, 4]] has ad − bc = −2 and inverse [[−2, 1], [3/2, −1/2]].

Why does my matrix have no inverse?

A matrix has an inverse only when its determinant is not 0. A determinant of 0 means one row (or column) can be made from the others, so the matrix squashes space flat and cannot be undone. The rank in the RREF tool tells you how many rows are truly independent.

How do I solve a system of equations with a matrix calculator?

Write the coefficients and the right-hand side of each equation as one row of an augmented matrix, choose Row echelon form (RREF) and rank, and read the answers from the last column. For 2x + y = 5 and x − y = 1, type [[2, 1, 5], [1, −1, 1]] and the RREF [[1, 0, 2], [0, 1, 1]] gives x = 2, y = 1.

What is the Gauss-Jordan method?

It is the method of row operations that turns a matrix into reduced row echelon form, with a leading 1 in each row and 0s above and below. Applied to [A | I] it produces [I | A⁻¹], which is how this calculator finds inverses of 3 × 3 and larger matrices.

How do I calculate a matrix on a Casio fx-991ES PLUS?

Switch to MATRIX mode, store your matrices in MatA, MatB or MatC (up to 3 × 3), then build the calculation, such as det(MatA), Trn(MatA) or MatA⁻¹; the answer appears as MatAns. For matrices larger than 3 × 3, or for exact fraction answers, use this page.

Why are the answers fractions?

Inverses and row reductions divide by numbers such as the determinant, so exact answers are often fractions like 3/4. Fractions never lose precision; choose Decimals to see the same answers with 10 significant digits.

Can the calculator find eigenvalues?

Not directly. For a 2 × 2 matrix the eigenvalues solve λ² − (trace)λ + det = 0, and the Determinant option gives both the trace and the determinant, so the Quadratic Formula Calculator can finish the job. For [[2, 1], [1, 2]], λ² − 4λ + 3 = 0 gives λ = 1 and 3.

What are matrices used for in real life?

They solve systems of equations in engineering and economics, rotate and scale images in computer graphics and games, describe electrical circuits, store data tables in statistics, and hold the weights of machine-learning models. Any time many quantities change together in a linear way, a matrix keeps the bookkeeping tidy.

How big can the matrices be?

Up to 10 rows and 10 columns each. All the work is exact, so even a 10 × 10 determinant of whole numbers is a whole number, with no rounding errors.
