What a root of a number is

A root undoes a power. The square root of 49 is 7 because 7² = 49, and the cube root of 64 is 4 because 4³ = 64. In general, the n-th root of x is the number that gives x when it is multiplied by itself n times. In the symbol ⁿ√x, the small n is the index (left out for a square root), x is the radicand and √ is the radical sign.

This root calculator works out square roots, cube roots and any other root, including decimal indexes, negative numbers and fractions. For whole numbers it also gives the simplified radical (surd) form, such as 6√2, with the steps you would write in a Matric or O-level exam, and a check line that raises the answer back to the power.

How to use the root calculator

  • Choose a tab: Square root, Cube root or Any root.
  • Square root: type the Number. Whole numbers, decimals and fractions such as 9/16 all work; the page starts with 72.
  • Cube root: type the Number; negative numbers have a real cube root. The page starts with 54.
  • Any root: type the Root n (the index), such as 4 for a fourth root or 2.5 for a decimal root, and the Number. The page starts with the 4th root of 81.
  • Read the root at the top, then the Simplified form (when the root is not a whole number), the Check line and the root written As a power, such as 72^(1/2).

With the defaults you get √72 = 6√2 ≈ 8.4852813742386, ∛54 = 3∛2 ≈ 3.7797631496846 and ⁴√81 = 3 exactly.

How to calculate a root without a calculator

Start by trapping the root between two perfect squares. 50 lies between 49 and 64, so √50 is a little more than 7. Then improve the guess by dividing and averaging, an old method often called the Babylonian or Heron's method: divide the number by your guess and average the guess with the answer.

For √50: 50 ÷ 7 = 7.142857, and the average of 7 and 7.142857 is 7.071429. Next, 50 ÷ 7.071429 = 7.070707, and the average is 7.071068, already correct to six decimal places (√50 = 7.0710678…). Each round roughly doubles the number of correct digits.

Cube roots work the same way with a different average: new guess = (2 × guess + number ÷ guess²) ÷ 3. For ∛100, start at 4.6 because 4.6³ is close to 100. 100 ÷ 4.6² = 4.7259, and (9.2 + 4.7259) ÷ 3 = 4.6420. One more round gives 4.641589, and the true value is 4.6415888.

Roots of negative numbers, fractions and decimals

  • Odd roots of negative numbers are real and negative: ∛(−27) = −3, because (−3)³ = −27.
  • Even roots of negative numbers are not real. With the imaginary unit i = √−1, √(−16) = 4i; the calculator says so and gives that answer.
  • Fractions: take the root of the top and the bottom. √(9/16) = 3/4 and ∛(8/27) = 2/3.
  • Decimals: √0.25 = 0.5 and √0.01 = 0.1. A root of a number between 0 and 1 is bigger than the number itself.
  • Decimal and negative indexes: the 2.5th root of 10 is 10^(1/2.5) = 10^0.4 ≈ 2.5119, and a −2nd root is 1 ÷ the square root.

Root rules and the root formula as a power

Every root can be written as a power: ⁿ√x = x^(1/n), and the m-th power of a root is x^(m/n). So 8^(2/3) = (∛8)² = 2² = 4. The usual rules follow: √(a × b) = √a × √b, √(a ÷ b) = √a ÷ √b, and ⁿ√(xⁿ) = x for positive x.

One rule that does not exist: √(a + b) is not √a + √b. √(9 + 16) = √25 = 5, while √9 + √16 = 7. In Excel or Google Sheets, =SQRT(72) gives a square root and =81^(1/4) or =POWER(81, 1/4) gives any other root.

Roots of numbers and roots of equations

The word root has a second meaning in algebra: a root (or zero) of an equation is a value of x that makes it true. The roots of x² − 5x + 6 = 0 are 2 and 3. The quadratic formula, x = (−b ± √(b² − 4ac)) ÷ 2a, uses a square root to find them; the Quadratic Formula Calculator does that with the steps.

Root mean square (RMS) is a third use: square the values, average them and take the square root. For 3, 4 and 5 the RMS is √((9 + 16 + 25) ÷ 3) = √(50 ÷ 3) ≈ 4.0825, a little above the ordinary average of 4.

Common mistakes

  • Taking out a factor that is not a perfect square: √72 = √8 × √9 = 3√8 is not finished, because 8 still holds 4.
  • Forgetting that a positive number has two square roots, +7 and −7 for 49. The √ sign means the positive one; equations like x² = 49 need both.
  • Writing √(−16) = −4. The square of −4 is +16, so the answer is 4i.
  • Splitting a root over a sum, as in √(a + b) = √a + √b.

How it works

Pick square root, cube root or any root, and type the number. The n-th root of a number is the value that gives the number back when it is multiplied by itself n times: the cube root of 27 is 3 because 3 × 3 × 3 = 27. For whole numbers the steps also simplify the root by taking out the largest perfect square (or cube, and so on), the way it is done in school: √72 = √36 × √2 = 6√2. Perfect powers come out exactly, the decimal has 14 significant digits, and the check line raises the answer back to the power.

The formula

  • ⁿ√x = x^(1/n): the number that, raised to the power n, gives x
  • Simplify: if x = a^n × b, then ⁿ√x = a × ⁿ√b (for example √72 = √(36 × 2) = 6√2)
  • Odd roots of negative numbers are negative: ∛(−27) = −3
  • Even roots of negative numbers are imaginary: √(−16) = 4i, where i = √−1
  • Any other index (decimal or negative): ⁿ√x = e^(ln x ÷ n), for x > 0

A worked example

√72: the largest perfect square that divides 72 is 36 = 6², and 72 = 36 × 2. So √72 = √36 × √2 = 6√2. Since √2 ≈ 1.4142135623731, √72 ≈ 6 × 1.4142135623731 = 8.4852813742386.

Questions

How do I calculate the root of any number?

Use the Any root tab: type the index n and the number. By hand, raise the number to the power 1 ÷ n, so the 4th root of 81 is 81^(1/4) = 3, and the 5th root of 32 is 2.

What is the value of root 2 and root 3?

√2 ≈ 1.41421356 and √3 ≈ 1.73205081. Both go on for ever without repeating, so they are usually left as √2 and √3 in exact answers.

How do I calculate a square root without a calculator?

Find the nearest perfect square for a first guess, then divide the number by the guess and average the two; repeat. For √50, 7 → 7.071429 → 7.071068 in two rounds.

How do I find the square root of a fraction?

Take the square root of the numerator and of the denominator: √(9/16) = 3/4. If the bottom is not a perfect square, simplify both parts or type the fraction above.

What is the difference between a square root and a cube root?

A square root is the number that times itself gives x (√49 = 7); a cube root is the number that times itself three times gives x (∛343 = 7). Negative numbers have a real cube root but no real square root.

What does simplifying a square root mean?

It means taking every perfect square factor out from under the root sign. 72 = 36 × 2, and √36 = 6, so √72 = 6√2. The simplified form is exact, while the decimal 8.4852813742386 is rounded.

Can I take the square root of a negative number?

Not as a real number, because any real number squared is positive or zero. Using the imaginary unit i = √−1, the answer is √(−16) = √16 × i = 4i, and the result shows it with a short note.

Why does a cube root of a negative number work?

Because a negative number multiplied by itself three times stays negative: (−3) × (−3) × (−3) = −27. So ∛(−27) = −3. The same is true for every odd root.

What is a root with a decimal index, such as 2.5?

The 2.5th root of x is x to the power 1/2.5, which is x^0.4. So the 2.5th root of 10 is 10^0.4 ≈ 2.5118864315096. Raising that back to the power 2.5 gives 10 again.

How do I write a square root or cube root in Excel?

Use =SQRT(number) for a square root and =number^(1/3) for a cube root, or =POWER(number, 1/n) for any root. For a negative number's cube root, write =-(8^(1/3)) to get −2.

Is this a root calculator for quadratic equations?

No, it finds roots of numbers. For the roots of an equation such as x² − 5x + 6 = 0, use the Quadratic Formula Calculator, which gives x = 2 and x = 3 with the steps.
