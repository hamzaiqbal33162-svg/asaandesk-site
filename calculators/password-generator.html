What a random password generator does

A password generator makes a password by drawing characters at random instead of letting a person choose them. People pick names, dates, keyboard patterns and common words, and attackers try those first. A random password has no pattern to guess, so the only attack left is trying every possibility, and a long one makes that hopeless.

This free password generator works entirely in your browser. Each character comes from the browser's cryptographic random number source (Web Crypto), every allowed character is equally likely, and the password is never sent to a server, written into the page address or stored. It can make anything from a 4-digit PIN to a 5,000-character key.

How to use the password generator

  • Set the Password length. It starts at 16 characters and accepts 4 to 5,000; the hint suggests 15 or more for an important account.
  • Tick the kinds of character allowed: Lowercase letters (a-z), Capital letters (A-Z), Numbers (0-9) and Symbols. All four are on by default, and every kind you tick appears at least once.
  • Under More options, Leave out look-alike characters (on by default) drops i l o I L O 0 and the marks ` ' " - _ : ; . , | so the password is easy to read and type.
  • Leave out brackets (on by default) drops < > ( ) [ ] { }, which some websites refuse.
  • Use each character only once (off by default) stops any character from appearing twice.
  • Press Generate for a new password, or change any option. Use the copy button, then paste the password straight into a password manager.

Understanding the results

Under the password you see its Strength label and the bits of entropy, the Characters to choose from (the pool, split by kind), and the number of Possible passwords. The gauge shows where the password falls on a scale from 0 to 144 bits. With the default settings the pool is 23 lowercase letters, 23 capitals, 9 numbers and 13 symbols, 68 characters in all; with every option relaxed it is 93.

How to calculate password entropy and combinations

The number of possible passwords is the pool size raised to the power of the length: N^L. Entropy is the same number written in bits, L × log₂ N, because 2 to the power of the entropy equals N^L. For 12 characters from the default pool that is 68^12, about 9.8 × 10²¹ passwords, or 12 × 6.087 = 73.0 bits.

When each character may be used only once, the count is N × (N − 1) × … for L factors, so 16 unique characters from 68 give 94.6 bits instead of 97.4. The rule that each ticked kind appears at least once also removes a very small share of the possibilities; like other generators, the figure shown leaves that out.

These formulas only hold for truly random passwords. A password you invent, such as Karachi@2024, has far less real entropy than its length suggests, because it follows a pattern that cracking tools try early.

What current password rules say (NIST 2025)

The US National Institute of Standards and Technology updated its digital identity guidance as SP 800-63B-4 in July 2025. Many organisations worldwide follow it. Rules change, so check the current version for any policy you write.

  • A password used on its own should be at least 15 characters; one used with another factor, such as a code on your phone, may be as short as 8.
  • Services should allow passwords of at least 64 characters, accept all printable ASCII characters and the space, and let you paste from a password manager.
  • Services should not force mixtures such as one capital and one symbol, and should not make you change passwords on a schedule; a change is needed when there is evidence the password was exposed.
  • New passwords should be checked against lists of common, expected and breached passwords.
  • The US Cybersecurity and Infrastructure Security Agency (CISA) advises at least 16 characters, a different password for every account, a password manager, and multi-factor authentication on important accounts.

Random passwords or passphrases made of words

A passphrase is several random words, which is easier to remember and to type on a phone. This tool makes character passwords, not word lists, but the same entropy maths applies. With the Electronic Frontier Foundation's dice list of 7,776 words, each word drawn at random adds log₂ 7,776 = 12.9 bits, so the six words the EFF suggests give about 77 bits, similar to a 13-character random password from the default set.

Use a passphrase for the few secrets you must type from memory, such as a password manager's master password or your computer login. Use long random passwords from this generator for everything stored in the manager. The words must be chosen at random; a favourite quote or song line is easy to guess.

Passwords for Wi-Fi, Google accounts and PIN codes

  • Wi-Fi (WPA2 personal): the passphrase must be 8 to 63 printable ASCII characters. Every symbol this generator uses is printable ASCII, so a 20 to 30 character password works; leave look-alikes out if guests will type it from a card.
  • Google and Gmail: Google accepts letters, numbers and ASCII symbols, rejects accented characters and a space at the start or end, and suggests at least 12 characters. The default settings meet all of that.
  • PIN codes: tick only Numbers, set the length to 4 or 6, and untick Leave out look-alike characters so that 0 can appear. A 4-digit PIN has only 10,000 possibilities (13.3 bits), so it is only reasonable where the card or phone limits how many wrong tries are allowed.
  • Old systems with limits: if a site allows only, say, 12 characters and no symbols, use the longest length it accepts and untick what it refuses.

How to keep your passwords safe

  • Use a different password for every account, so one leak does not open the others.
  • Store them in a password manager rather than a notebook, phone note or spreadsheet; then you only need to remember one strong master password.
  • Turn on multi-factor authentication for email, banking and social media accounts.
  • Never send a password by message or email, and never type it into a page you reached from a link in a message.
  • Change a password at once if a service reports a breach or you suspect someone saw it; there is no need to change strong ones on a fixed schedule.
  • Do not reuse a generated password after you have shared it with someone, for example on a shared Wi-Fi network you later want to lock down.

How it works

Choose how long the password should be and which kinds of character it may use. Every character is picked by your browser's secure random number generator (Web Crypto), with every allowed character equally likely, and each kind you tick appears at least once. Look-alike characters such as l, 1 and I or O and 0 are left out by default, and so are brackets, which some websites refuse. The strength is measured in bits of entropy: each bit doubles the number of guesses an attacker would need. Nothing is sent to a server or saved, so copy the password into a password manager before you leave the page.

The formula

  • Pool size N = the number of different characters allowed
  • Entropy (repeats allowed) = length × log₂ N bits
  • Entropy (each character once) = log₂ (N × (N − 1) × … × (N − length + 1)) bits
  • Possible passwords = N to the power of the length = 2 to the power of the entropy
  • Strength: under 36 bits very weak, 36-47.9 weak, 48-59.9 good, 60-119.9 strong, 120 or more very strong

A worked example

16 characters from lowercase letters, capitals, numbers and symbols, with look-alikes and brackets left out: N = 23 + 23 + 9 + 13 = 68 characters, so the entropy is 16 × log₂ 68 = 16 × 6.09 = 97.4 bits (strong). Allowing every character (N = 93) gives 104.6 bits.

Questions

Is it safe to make a password on a website?

Here, yes: the password is made inside your own browser with its secure random number generator. It is not sent to any server, not put in the page address and not stored, so nobody else ever sees it. Copy it into a password manager, then close the page.

How long should my password be?

For an account protected only by its password, use 15 characters or more; 16 random characters with all four kinds give about 97 bits, far beyond guessing. Where a site limits the length or the symbols, use the longest password it accepts and untick the kinds it refuses.

Is an 8 character password strong enough?

Only with a second factor. Eight random characters from the default set give 48.7 bits, rated good, but NIST now asks for at least 15 characters when the password is the only protection. Twelve characters already give 73 bits.

How do I calculate password entropy?

Multiply the length by log₂ of the number of possible characters. A 12-character password from 68 characters has 12 × log₂ 68 = 12 × 6.087 = 73.0 bits. The generator shows this figure for every password it makes.

How do I calculate how many combinations a password has?

Raise the number of possible characters to the power of the length. Four digits give 10^4 = 10,000 combinations; 8 characters from all 93 give 93^8, about 5.6 × 10¹⁵. The result appears as Possible passwords.

What does entropy in bits mean?

It counts how many guesses an attacker would need in the worst case: n bits means 2 to the power n possible passwords. Every extra bit doubles the work, so 60 bits is a million times harder to guess than 40 bits. Length adds entropy faster than extra kinds of character.

Why leave out look-alike characters and brackets?

Characters like l, I and 1 or O and 0 are easy to misread when you type a password from paper or another screen, and some websites reject brackets or quote marks. Leaving them out makes the pool a little smaller, which you can make up for with one or two more characters.

What does "Use each character only once" do?

No character appears twice in the password. Some older systems ask for this. It makes the password slightly weaker for the same length, because there are fewer possible passwords, and the length can be at most the number of allowed characters.

Can it make a password with words?

No, it makes random characters. For a word passphrase, roll dice against a published word list such as the EFF's, which adds about 12.9 bits per word; six random words give about 77 bits.

Should I change my password every 90 days?

Not if it is long, random and unique. Current NIST guidance says services should not force changes on a schedule, only when there is evidence a password was exposed. Change it at once after a breach notice.

Can I use it for a Wi-Fi password?

Yes. Wi-Fi passphrases must be 8 to 63 printable ASCII characters, and every character this tool uses qualifies. A length of 20 to 30 with look-alikes left out is strong and still easy for guests to type.
