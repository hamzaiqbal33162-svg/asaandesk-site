heic2any 0.0.4 (published 2023-03-29), browser build dist/heic2any.min.js, unchanged.
Source: https://github.com/alexcorvi/heic2any  Licence: MIT (LICENSE-heic2any.md).

The heic2any bundle contains libheif compiled to JavaScript (with the libde265 HEVC decoder).
libheif and libde265 are LGPL-3.0 (https://github.com/strukturag/libheif, https://github.com/strukturag/libde265).
The file is loaded as a separate, replaceable script only when a HEIC/HEIF photo is opened in a browser
that cannot decode HEIC itself. The site already ships the same package through lib/docs.ts.
